# A题 数据格式规范（全队统一）

> **版本**：v1.1  
> **适用范围**：锂电池剩余寿命预测与梯次利用筛选优化（试题A）  
> **目的**：统一成员A、B、C之间的数据接口，避免字段名不一致、单位混乱导致的对接错误。

---

## 1. 总体约定

| 项目 | 约定 |
|------|------|
| 文件编码 | UTF-8 |
| 小数分隔符 | 点 `.`（禁止用逗号） |
| 缺失值 | 用空字符串或 `NaN`，禁止用 `-999` 等魔法数字 |
| 工况命名 | 固定格式 `T{温度}_C{倍率}_D{放电深度}`，例如 `T23_C1.0_D0.8` |
| 放电深度单位 | **小数形式**（0.8 表示 80%），全项目统一，禁止混用百分比 |
| 温度单位 | ℃ |
| 内阻单位 | Ω |
| SOH 定义 | 容量保持率，范围 [0, 1] |

---

## 2. 核心数据表定义

### 2.1 时序数据表（成员A生成）

**推荐文件名**：`battery_timeseries.csv`

| 字段名 | 类型 | 含义 | 取值说明 | 必填 |
|--------|------|------|----------|------|
| `cycle` | int | 循环次数 | 从 1 开始递增 | 是 |
| `SOH` | float | 健康状态（容量保持率） | **0.70 ~ 1.00**（EOL=70%；观测含噪声，实际最低可至 ~0.695） | 是 |
| `resistance` | float | 内阻 | > 0 | 是 |
| `T` | float | 环境温度 | 建议取值 10 / 23 / 35 / 45（[Str24]；25 仅作格式示例，可扩展） | 是 |
| `c_rate` | float | 充放电倍率 | 建议取值 0.5 / 1.0 / 2.0（LFP 快充可含 3.0；[Sto19][Str24]） | 是 |
| `dod` | float | 放电深度 | **小数**，如 0.7 / 0.8 / 0.9（对应百分比 70 / 80 / 90%） | 是 |
| `condition` | str | 工况唯一标识 | 如 `T23_C1.0_D0.8` | 是 |
| `cond_id` | int | 工况编号 | 0, 1, 2, ... | 推荐 |
| `stage` | str | 退化阶段（SOH 阈值法，**接口标准**） | `正常运行` / `性能劣化` / `失效临界` | 推荐 |
| `capacity_Ah` | float | 参考放电容量（Ah） | 问题2 多特征融合 SOH 的输入 [Wil20] | 推荐 |
| `ccct_min` | float | 恒流充电时长（min，老化缩短） | 同上 | 推荐 |
| `cvct_min` | float | 恒压充电时长（min，老化增加） | 同上 | 推荐 |
| `ce` | float | 库伦效率 | 同上 | 推荐 |

**阶段划分标准（统一代码）**：

```python
def get_stage(soh: float) -> str:
    if soh >= 0.90:
        return "正常运行"
    elif soh >= 0.80:
        return "性能劣化"
    else:
        return "失效临界"
```

> 注：`stage`（SOH 阈值法）为**交接接口标准**，代码全队统一。问题1 建模所需的"曲线形态三阶段"（初始陡降→线性→拐点后加速，[Sto19]）在建模数据中以 `phase_label`（1/2/3）与 `knee_cycle` 列保留，两套划分并存、互不覆盖。

---

### 2.2 退役电池最终状态表（成员A → 成员B/C）

**推荐文件名**：`battery_final_states.csv`

在时序表每个 `condition` 的**最后一行**基础上形成，字段与时序表保持一致，并增加：

| 字段名 | 类型 | 含义 | 说明 |
|--------|------|------|------|
| （继承时序表全部字段） | - | - | 取最后时刻状态 |
| `RUL` | float | 剩余寿命预测值（循环数） | 由成员B计算后填入 |
| `grade` | str | 梯次利用等级 | 由成员C计算后填入 |

---

### 2.3 健康指标表（成员B输出，供成员C使用）

**推荐文件名**：`battery_health_indicators.csv`

| 字段名 | 类型 | 含义 | 来源 |
|--------|------|------|------|
| `cond_id` | int | 电池/工况编号 | A |
| `condition` | str | 工况标识 | A |
| `SOH` | float | 最终健康状态 | A 或 B预测 |
| `resistance` | float | 最终内阻 | A |
| `RUL` | float | 剩余寿命（循环数） | **B负责计算** |
| `T` | float | 温度 | A |
| `c_rate` | float | 倍率 | A |
| `dod` | float | 放电深度 | A |

> 注意：早期代码中的 `RUL_proxy` 统一更名为 **`RUL`**。

---

### 2.4 优化选中结果表（成员C输出）

**推荐文件名**：`selected_batteries.csv`

在健康指标表基础上增加：

| 字段名 | 类型 | 含义 |
|--------|------|------|
| `selected` | int | 是否被选入最终编组（1=是，0=否） |
| `cluster` | int | 聚类分组编号（可选） |
| `grade` | str | 最终分级结果 |

**分级标准（统一代码）**：

```python
def get_grade(soh: float) -> str:
    if soh >= 0.85:
        return "一级梯次"
    elif soh >= 0.75:
        return "二级梯次"
    else:
        return "建议回收"
```

## 3. 与HTML可视化界面的字段对应

| HTML交互界面字段 | 统一数据字段 | 说明 |
|------------------|--------------|------|
| `T` | `T` | 完全一致 |
| `C` | `c_rate` | 注意大小写差异 |
| `DoD` | `dod` | HTML显示为百分比（80），数据表统一用小数（0.8） |
| `z` / `Ea` / `alpha` / `beta_d` | 模型参数 | 仅用于数据生成或交互演示，不进入最终业务数据表 |

**强制约定**：数据表中的 `dod` 永远使用小数形式，HTML界面需要显示时再 `*100` 转为百分比。

## 5. 数据流转关系

```
成员A
  │
  ├─ 生成 → battery_timeseries.csv          （完整时序）
  │
  └─ 提取 → battery_final_states.csv        （每块电池最终状态）
                │
                ▼
             成员B
                │
                ├─ 读取最终状态 + 时序特征
                ├─ 训练SOH/RUL模型
                └─ 输出 → battery_health_indicators.csv   （含RUL）
                              │
                              ▼
                           成员C
                              │
                              ├─ 分级 + 多目标优化
                              └─ 输出 → selected_batteries.csv
```
