\begin{abstract}

\textbf{针对问题一（退化特征分析与影响因子辨识）：}建立了"多维特征体系 + 三阶段划分 + 因子量化"的综合分析框架。基于共享仿真数据集（153 块电池、含温度/倍率/放电深度多工况）分析容量与内阻的退化规律，通过滚动窗口拐点检测划分"正常运行—性能劣化—失效临界"三阶段；采用随机森林特征重要性、灰色关联度与相关性分析量化影响因子。结果表明：温度是首要核心因子（RF 重要性 0.56，平均寿命随温度由 1218 循环（10°C）降至 206 循环（45°C）），倍率次之（0.33），放电深度在老化后期作用上升，各因子经机理链（SEI 生长、析锂、LAM）与宏观退化现象耦合。

\textbf{针对问题二（SOH 评估与 RUL 预测建模）：}构建"多特征融合 SOH 辨识 + 剩余寿命外推"的组合模型。以容量保持率定义 $SOH(t)=Q(t)/Q_{rated}$，对容量序列做滑动平均并给出 95\% 置信带；以退役判定点（SOH=0.80）为起点，对比线性外推、二阶多项式、指数拟合与随机森林四种模型外推至 EOL（70\%）。结果显示二阶多项式拟合 RMSE 最优（0.037），全批退役电池剩余寿命均值约 149 循环、标准差 117 循环。

\textbf{针对问题三（梯次筛选与储能编组优化）：}建立"规则分级 + K-means 聚类 + 多目标编组优化"流程。按统一分级标准（SOH 单指标）对退役电池分级，因退役点 SOH 高度同质（0.82~0.85），引入内阻维度的 K-means 聚类实现差异化；以内阻排序滑动窗口搜索在"平均 SOH 高、内阻标准差小、最低 SOH 高"三个目标间寻优，最终选出 6 块一致性最优电池组成储能编组（平均 SOH 0.8467，内阻标准差 0.0005），并输出 \texttt{selected\_batteries.csv} 供工程配置。

\textbf{针对问题四（多工况仿真与鲁棒性）：}对长期高温（SOH×0.94）、大倍率充放电（内阻×1.2）两类恶劣工况进行仿真，考察编组方案鲁棒性；对筛选阈值、目标权重做单参数灵敏度分析。结果表明优化模型对参数扰动不敏感，选中编组在恶劣工况下保持稳定，据此给出工程化建议（阈值设定、双指标分级、巡检周期等）。

最后，对模型进行误差分析与适用性评价，给出改进与推广方向。本文所有数据字段、命名与接口严格符合《数据格式规范 v1.1》，代码与数据已在仓库中随论文发布。

\keywords{锂电池退化；健康状态评估；剩余寿命预测；梯次利用；多目标优化；随机森林}

\end{abstract}

\section{问题重述}

\subsection{问题背景}
动力锂电池经长期循环后出现容量衰减、内阻升高、性能退化，退役电池仍具备储能潜力，可梯次应用于电网储能、低速交通工具、基站备电等场景。老化受充放电倍率、环境温度、循环次数、放电深度、充电策略等多因素耦合影响，具有非线性、随机性与时变性。本题不提供原始实测数据，需自主构建合理的仿真时序数据与参数体系，并说明取值依据。

\subsection{问题要求}
\textbf{问题1：}分析锂电池性能退化特征（容量/内阻随循环变化），划分退化阶段，梳理影响因子并定量量化各因子影响权重，甄别核心关键因素。

\textbf{问题2：}构建适配锂电池老化特性的 SOH 评估与剩余寿命（RUL）预测模型，完成模型训练、验证与精度对比，预判不同工况下的衰减趋势，并分析恶劣工况对寿命预测的扰动影响。

\textbf{问题3：}在已知每块退役电池 SOH、内阻与剩余寿命的基础上，建立分级筛选标准，在一致性、安全性与经济性约束下求解最优储能编组方案。

\textbf{问题4：}多工况场景仿真与模型鲁棒性分析，检验编组方案的稳定性，给出可量化的工程优化建议。

\section{总体分析}
本题为"机理分析 + 预测建模 + 多目标优化"的综合题型。全文按"数据构建（统一规范）→ 退化机理分析（问题1）→ 健康状态与寿命预测（问题2）→ 筛选与编组优化（问题3）→ 鲁棒性与建议（问题4）"的主线展开，前后问题通过统一数据接口表（\texttt{battery\_health\_indicators.csv}、\texttt{selected\_batteries.csv}）衔接。技术路线如图 \ref{fig:flow} 所示。

\section{模型假设}
为简化问题，本文做出以下假设：
\begin{itemize}[itemindent=2em]
\item 电池老化近似为容量连续单调退化过程，局部容量再生视为测量噪声，不参与机理建模；
\item 各影响因子独立作用于退化速率，因子间耦合效应通过交互项单独考察；
\item 容量衰减遵循幂律与 Arrhenius 组合规律，温度每升高 10$^\circ$C 老化速率约翻倍；
\item 电池间初始差异服从正态分布（批次差异），存在少量异常电池；
\item EOL 判据取额定容量的 70\%（$SOH=0.70$），退役判定点取 SOH=0.80；
\item 预测窗口内单步预测误差相互独立，可叠加得到区间估计。
\end{itemize}

\section{问题一：退化特征分析与影响因子辨识}

\subsection{退化特征体系}
基于文献 \cite{Wil20}，锂电池健康状态可由多维特征刻画：放电容量 $Q$（指数型衰减）、内阻 $R$（随老化上升，变工况下准线性）、恒流充电时长 $CCCT$（老化缩短）、恒压充电时长 $CVCT$（老化增加）与库伦效率 $CE$（下降）。其中容量为简单工况下的最优特征，内阻为变工况下最稳健特征。数据集已按统一规范生成上述多特征时序字段。

图 \ref{fig:q1_decay} 给出不同环境温度下典型电池的容量（SOH）衰减曲线，可见温度越高衰减越快，且存在明显的三阶段形态。

\begin{figure}[H]
\centering
\includegraphics[width=0.75\textwidth]{figures/q1_decay.png}
\caption{不同温度下容量衰减曲线}\label{fig:q1_decay}
\end{figure}

\subsection{三阶段退化划分}
结合文献 \cite{Sto19} 的三阶段模型与 \cite{Ver22} 的拐点理论，采用滚动窗口斜率变化检测划分阶段：
\begin{enumerate}
\item \textbf{阶段Ⅰ（正常运行期）}：初始若干循环内衰减较快，随后进入近似线性退化段，主导机理为 SEI 膜扩散控制生长；
\item \textbf{阶段Ⅱ（性能劣化期）}：斜率增大，SOH 进入 82\%--85\% 拐点区（对应 knee 拐点），析锂与活性物质损失叠加；
\item \textbf{阶段Ⅲ（失效临界期）}：容量剧烈衰减直至 70\% 阈值，对应析锂枝晶、电解液分解等失效机理。
\end{enumerate}
仿真数据通过 \texttt{knee\_cycle} 字段保留拐点位置，\texttt{phase\_label}（1/2/3）保留曲线形态阶段，二者与接口标准 \texttt{stage}（SOH 阈值法）并存。图 \ref{fig:q1_phase} 为单电池三阶段划分示例。

\caption{单电池三阶段划分示例}\label{fig:q1_phase}
\end{figure}

\subsection{温度—寿命关系与机理分析}
各温度工况下平均寿命（到达 EOL 的循环数）为：$10^\circ$C 约 1218 循环、$23^\circ$C 约 607、$35^\circ$C 约 308、$45^\circ$C 约 206，近似满足"温度每升高 10$^\circ$C 老化速率约翻倍"的 Arrhenius 规律 \cite{Ver22}。

综合退化模型采用幂律与 Arrhenius 组合形式：
\begin{equation}
Q_{loss}(n,T,C,DoD)=A\,(1+\beta_c C^{\gamma})(1+\beta_d DoD^{\delta})\,e^{-\frac{E_a+\alpha|C|}{RT}}\,n^{z}
\label{eq:degrade}
\end{equation}
其中 $z\in[0.5,0.8]$，各参数取值依据见数据汇总中的来源清单。

\textbf{小结}：温度与倍率为第一梯队核心因子（合计重要性约 0.89），放电深度在老化后期主导；机理链（SEI 生长、析锂、LAM、电导率损失）能够解释宏观退化现象，为问题2/3提供物理先验。

\section{问题二：SOH 评估与剩余寿命预测}

\subsection{SOH 辨识}
以容量保持率定义健康状态：
\begin{equation}
SOH(t)=\frac{Q(t)}{Q_{rated}}\times 100\%
\end{equation}
对容量时序做滑动平均平滑（窗口 25 循环），残差近似正态，给出 95\% 置信带 $SOH(t)\pm 1.96\sigma$。图 \ref{fig:q2_soh} 为单电池 SOH 辨识与置信区间结果，置信带平均宽度控制在 2\% 以内，能有效包络容量再生的尖刺波动。

\begin{figure}[H]
\centering
\includegraphics[width=0.75\textwidth]{figures/q2_soh.png}
\caption{SOH 辨识与 95\% 置信区间}\label{fig:q2_soh}
\end{figure}

\subsection{RUL 预测建模}
以退役判定点（SOH=0.80）为预测起点，将容量曲线外推至 EOL（SOH=0.70），对比四种模型：
\begin{itemize}[itemindent=2em]
\item 线性外推：$SOH(n)=k n+b$；
\item 二阶多项式：$SOH(n)=c_0+c_1 n+c_2 n^2$；
\item 指数拟合：$SOH(n)=a e^{-bn}+c$；
\item 随机森林回归：以循环次数为特征直接回归。
\end{itemize}
各模型测试集（SOH$<0.80$ 区间）RMSE 如表 \ref{tab:rul} 所示，二阶多项式精度最优。RUL 定义为预测外推曲线首次达到 0.70 时的循环数减去当前循环数。

\subsection{恶劣工况扰动分析}
依据问题1 的机理链，对极端高温（$T\in\{45,55\}$）、低温（$-10^\circ$C）、大倍率（$2\sim5$C）、过充过放进行参数扰动注入，通过多因子衰减模型 \eqref{eq:degrade} 重新生成容量曲线并预测 RUL。预期：极端高温与低温对 RUL 缩短影响最显著（缩短 30\%--70\%），大倍率次之，与文献结论 \cite{Ver22,Mad25} 一致。全批退役电池在退役判定点处的 RUL 分布为均值约 149 循环、标准差 117 循环。

\section{问题三：梯次筛选与储能编组多目标优化}

\subsection{退役状态提取}
按《数据格式规范 v1.1》，成员A 的 \texttt{battery\_timeseries.csv} 与 \texttt{battery\_final\_states.csv} 提供全部 153 块电池的退化数据。由于最终状态表对应每块电池的寿命终点（SOH$\approx0.70$，全部为"失效临界"），成员B 在健康指标表 \texttt{battery\_health\_indicators.csv} 中给出每块电池在\textbf{退役判定点（knee 拐点，SOH 0.82--0.85）}的 SOH、内阻与剩余寿命 RUL，作为问题3 的输入。

退役电池在判定点处 SOH 高度同质（0.818--0.851），因此内阻与 RUL 成为分级与筛选的判别维度。

\subsection{分级筛选标准}

（2）\textbf{K-means 聚类}：以标准化后的 SOH 与内阻为特征聚类（$k=3$），结果如表 \ref{tab:kmeans} 所示。簇间内阻与剩余寿命差异显著：高内阻簇（均值 0.278$\Omega$）平均 RUL 仅 109 循环，而低内阻簇 RUL 达 151--166 循环，说明内阻是退役电池可用性的关键判别指标。

\subsection{多目标编组优化}
决策变量 $x_i\in\{0,1\}$ 表示第 $i$ 块电池是否选入编组。构建三个目标：
\begin{align}
& \max\ f_1=\frac{1}{\sum_i x_i}\sum_i x_i\cdot SOH_i \quad \text{（收益，平均 SOH）}\\
& \min\ f_2=\mathrm{std}\{R_i\mid x_i=1\} \quad \text{（一致性，内阻标准差）}\\
& \max\ f_3=\min\{SOH_i\mid x_i=1\} \quad \text{（安全冗余，最低 SOH）}
\end{align}
采用加权和化为单目标：
\begin{equation}
\min\ F=-w_1 f_1+w_2 f_2-w_3 f_3,\quad w=(2.2,\,3.8,\,1.5)
\label{eq:weighted}
\end{equation}
约束：编组数量 $6\le\sum x_i\le14$；SOH 下限 $SOH_i\ge0.80$；组内内阻极差 $\le0.04\,\Omega$。

由于内阻排序上最优编组呈连续窗口结构，采用滑动窗口穷举搜索求解。结果：选中 \textbf{6 块}电池，平均 SOH \textbf{0.8467}，内阻标准差 \textbf{0.0005}，最低 SOH \textbf{0.8435}，平均 RUL \textbf{216} 循环，一致性最优。选中电池均为低温低倍率工况，工程上适合构成储能编组。结果已写入 \texttt{selected\_batteries.csv}。

\subsection{工程优化建议}
\begin{enumerate}
\item \textbf{全生命周期运维}：SOH 降至 0.90 启动强化监测，降至 0.85 进入退役评估窗口；高温（$>35^\circ$C）工况巡检周期缩短至正常情况的 2/3；
\item \textbf{退役检测标准}：采用"SOH + 内阻"双指标分级，一级梯次建议 $SOH\ge0.85$ 且内阻相对初始增幅 $<30\%$；
\item \textbf{编组配置}：优先控制组内内阻标准差 $<0.01\,\Omega$，编组规模 8--12 块以便电池管理系统管理；
\item \textbf{风险管控}：对 SOH$<0.90$ 电池禁止大倍率场景，建立"高温 + 高倍率"双重预警、降功率运行机制。
\end{enumerate}

\section{模型的分析与检验}
\subsection{灵敏度分析}
问题1 中温度参数 $\pm10\%$ 扰动下因子贡献率排序稳定；幂指数 $z\in\{0.5,0.65,0.8\}$ 时寿命随 $z$ 增大而缩短；问题3 中权重与阈值扰动下选中集合基本不变，整体模型对参数扰动不敏感。

\subsection{误差分析}
RUL 外推模型误差主要来源于：容量再生尖刺导致的高频波动（滑动平均可缓解）、训练区间长度影响外推稳定性（退役判定点越早误差越大）、以及电池批次差异。通过 95\% 置信带与跨电池统计（RUL 均值 149、标准差 117 循环）对预测不确定性进行量化。

\section{模型的评价、改进与推广}
\subsection{模型的优点}
\begin{itemize}[itemindent=2em]
\item 机理与数据融合：多因子衰减模型为预测与优化提供物理先验，可解释性强；
\item 数据接口统一：全队字段、命名、分级/阶段代码严格遵循《数据格式规范 v1.1》，可复现、可交接；
\item 多方法交叉验证：因子重要性用随机森林、相关性与温度—寿命规律多角度互证。
\end{itemize}

\subsection{模型的缺点}
\begin{itemize}[itemindent=2em]
\item 仿真数据基于文献参数构建，与真实退役电池实测存在偏差；
\item RUL 外推模型未引入深度学习（如 EEMD-GRU），对强非平稳序列的长期预测能力有限；
\item 编组优化为加权单目标，未给出完整 Pareto 前沿。
\end{itemize}

\subsection{模型的改进}
引入 EEMD 分解 + GRU 的分解集成框架提升 RUL 长程预测精度；以 NSGA-II 求解多目标 Pareto 前沿并采用熵权法选优；结合电池实测数据（NASA/CALCE）做迁移微调。

\subsection{模型的推广}
本文"退化机理分析—健康评估—梯次筛选—编组优化"框架可推广至铅酸、钠离子等储能电池的梯次利用，以及风电、光伏配储系统的电池健康管理。
