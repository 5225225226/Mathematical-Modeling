# 论文精读：退役锂电池两步学习法快速聚类（Fast Clustering of Retired Lithium-ion Batteries for Secondary Life with A Two-step Learning Method）

> **与A题的关系**：本文是A题**问题3（退役锂电池梯次筛选与储能编组）的核心参考**——提供了完整的"**两步学习方法**"：第一步用回归模型（GPR 最优）从脉冲测试数据估计电池容量，第二步用 K-means/GMM 聚类对同类型电池分组；并给出 507 个 18650 NCM 电池的真实测试流程、聚类结果表与自动分拣机工程实现，可直接指导 A 题的筛选编组建模与仿真数据构建。

## 一、论文概述

### 1.1 研究背景与目标
- 退役锂电池（retired LIBs）仍具储能能力，但**来自不同制造商、不同批次**的电池性能差异大，不能直接混用；梯次利用（二次生命，secondary life）要求**同制造商、同型号、同批次、同性能**，因此必须对退役电池进行快速、准确的分选。
- 传统分选需要完整充放电循环测试，耗时且成本高；本文提出以**短时脉冲测试数据**替代完整循环，用两步学习法实现**快速、低成本的容量估计 + 聚类分组**。

### 1.2 核心贡献（两步学习方法）
- **Step 1（分型）**：按标签、历史信息或其他参数，先把退役电池分为不同类型（不同厂商/型号/批次）；
- **Step 2（分选）**：对不同类型分别建立分选模型——收集退役电池的**脉冲数据**，先做**容量估计回归**，再做**聚类分组**，实现同性能电池的快速准确分类；
- 配套研发了**自动分拣机**（自动测试探针阵列 + 聚类模块），把聚类结果实时插入到分拣流程中。

### 1.3 数据规模
- 共购买 **507 个 18650 圆柱形 LiNi(1-x-y)CoxMnyO2 (NCM)/石墨电池**（来自不同商业公司）。
- 实验包含：条件化充放电、老化循环、容量标定、**多倍率脉冲测试**、**热测量**。

## 二、核心知识点提炼

### 2.1 实验测试流程（仿真数据/实验设计可直接参考）
**测试环境**：25℃ 恒温受控环境，充放电电流 1A。

1. **条件化充电（conditioning）**：按制造商推荐方法——**恒流 0.5A 充电 + 恒压 4.2V，C/200 或 1/2 h 截止**；
2. **容量标定（基准）**：老化循环之后，先用 1A 将电池充满，再用 **0.5A 放电**得到**放电容量**，视为该电池的"测试容量"，作为容量估计的基准（benchmark）；
3. **脉冲测试（pulse test）**：
   - 先以 **1A 充电 6 分钟**，静置 30 分钟使电压稳定；
   - 然后 **0.5A 充电 10 s → 静置 30 s → 0.5A 放电 10 s → 静置 30 s**；
   - 之后依次用电流 **0.6 A、0.7 A、0.8 A、0.9 A、1.0 A、1.25 A、1.5 A、1.75 A、2.0 A** 重复上述充放电；
4. **热测量（thermal measurement）**：对选出的 6 类电池各取代表，测量充放电过程温度变化（Fig. S8、S9）——记录单电池温度随电压/时间的变化、6 类电池的温度变化曲线与汇总。

**关键洞察**：脉冲测试只消耗几分钟，却能提取足以估计容量的响应特征，远快于完整循环测试——这是"快速分选"的核心卖点。

### 2.2 容量分布与异常电池
- 507 个电池的放电容量分布（Fig. S3）：用上述方法采集，按从大到小排列展示，存在明显分布离散度（正是需要分选的原因）。
- 某些簇（如 Cluster 12，Fig. S4）包含**异常电池**——聚类后应检测并剔除异常样本，保证编组一致性。

### 2.3 分选框架（Fig. S12）
1. **Step 1**：按标签、历史信息或参数把退役电池筛成不同类型（因为不同厂家/批次性能不同）；
2. **Step 2**：针对不同电池类型分别建立分选模型；采集退役电池脉冲数据后，由**自动分拣机**实现同性能电池快速准确分类；
3. 二次利用硬性要求：**同制造商、同型号、同批次、同性能**。

### 2.4 自动分拣机（Fig. S13）
- 包括自动分拣机设计、测试核心组件、分拣设备实物、电池测试探针阵列、聚类模块（可插入聚类结果输出）；
- 初始为"原始状态"，插入聚类结果后（如 7 个电池被聚为一簇）即可自动化分拣。

## 三、关键技术方法

### 3.1 第一步：容量估计回归模型对比
四种回归方法对比（图 S11、表 S2~S5）：
- **LR**：Linear Regression（线性回归）
- **SVR**：Support Vector Regression（支持向量回归）
- **Bayes**：Bayesian Ridge Regression（贝叶斯岭回归）
- **GPR**：Gaussian Process Regression（高斯过程回归）

**评价指标**：RMSE（越低越好）、相关系数 R²（越高越好）。

**结论**（原文）：GPR 显著优于其它方法；当**训练样本/总样本比例 < 1/3** 时，GPR 优势尤其明显；因此 **GPR 是电池容量估计的最优机器学习模型**。LR、SVR、Bayes 在训练样本充足时也较有效。

### 3.2 第二步：聚类分组
- 在容量估计（以及 OCV、脉冲特征等）基础上，对同一类型电池做无监督聚类，把性能接近的电池分入同一簇，供储能编组使用。
- 本文给出 **K-means** 与 **GMM** 两种算法的完整伪代码（见 3.3、3.4）。

### 3.3 K-means 算法伪代码（Fig. S6）
```
输入：数据集 X = [x₁, x₂, ..., x_N]ᵀ，聚类数 K；
输出：聚类结果。
1. 随机选 K 个样本作为初始聚类中心，记为 C = [c₁, c₂, ..., c_K]ᵀ；
2. 设置聚类变化标志 sign = 1；
3. while sign == 1 do
4.   for 每个 x_i ∈ X do
5.     求 x_i 与每个中心 c_j 的最小距离 d(x_i, c_j) = ||x_i − c_j||₂；
6.     令 j = argmin d(x_i, c_j)，将 x_i 分到簇 j（记为 Cluster_j）；
7.   end for
8.   对每个 c_j ∈ C 按 c_j = (1/N_j) Σ_{x∈Cluster_j} x 更新中心，N_j 为 Cluster_j 样本数；
9.   if C 不再变化 then sign = 0; end if
10. end while
11. 输出聚类结果。
```

### 3.4 GMM 算法伪代码（Fig. S7）
高斯混合模型（Gaussian Mixture Model）用 EM 算法求解。输入数据集 X = [x₁,...,x_N]ᵀ 与簇数 K，输出各样本属于簇 C 的后验概率 P、每个高斯分量的均值 μ 与协方差 Σ。

```
13. E-step：记簇向量 C = [c₁,...,c_K]ᵀ、隐变量 Z = [z₁,...,z_N]ᵀ。完整数据 (X,Z) 对数似然期望：
    Q(θ, θ^(t)) = E_{Z|X,θ^(t)}[ln p(X,Z|θ)]
               = Σ_{k=1}^{K} Σ_{i=1}^{N} [ln p_k + ln N(x_i | μ_k, Σ_k)] · p(z_i = c_k | x_i, θ^(t))
    其中待估参数 θ = {P=[p₁,...,p_K]ᵀ, μ=[μ₁,...,μ_K]ᵀ, Σ=[Σ₁,...,Σ_K]ᵀ}。
14. 设置迭代标志 sign = 0；
15. while sign == 0 do
16.  M-step：最大化期望更新 θ：θ^(t+1) = argmax_θ Q(θ, θ^(t))。
    分别对 p_k、μ_k、Σ_k 求导并置零，得更新式：
    p_k^(t+1) = (1/N) Σ_{i=1}^{N} p(z_i = c_k | x_i, θ^(t))
    μ_k^(t+1) = [Σ_{i=1}^{N} p(z_i = c_k | x_i, θ^(t)) · x_i] / [Σ_{i=1}^{N} p(z_i = c_k | x_i, θ^(t))]
    Σ_k^(t+1) = [Σ_{i=1}^{N} p(z_i = c_k | x_i, θ^(t)) · (x_i − μ_k^t)(x_i − μ_k^t)ᵀ] / [Σ_{i=1}^{N} p(z_i = c_k | x_i, θ^(t))]
17. if t 达到收敛迭代次数 then sign = 1; else t = t+1; end if
18. end while
19. 输出聚类结果。
```
（注：GMM 相比 K-means 能给出软划分（后验概率）与簇的椭圆形状，更鲁棒于簇形状不均/重叠。）

## 四、实验与结论

### 4.1 四种回归方法在不同训练比例下的性能（表 S2~S5）
训练样本比例从 1/12 到 11/12（每类内训练样本数从 3 到 34），测试样本数相应从约 200 降到 18。

**LR（表 S2）**：
| 训练比例 | 训练样本 | 测试样本 | RMSE | R² |
|---|---|---|---|---|
| 1/12 | 18 | 200 | 0.278963 | 0.330396 |
| 1/4 | 56 | 162 | 0.112832 | 0.905106 |
| 1/2 | 108 | 110 | 0.078763 | 0.956696 |
| 11/12 | 200 | 18 | 0.067425 | 0.961965 |

**SVR（表 S3）**：
| 训练比例 | 训练样本 | 测试样本 | RMSE | R² |
|---|---|---|---|---|
| 1/12 | 18 | 200 | 0.102214 | 0.902518 |
| 1/4 | 56 | 162 | 0.062783 | 0.970967 |
| 1/2 | 108 | 110 | 0.054921 | 0.959158 |
| 11/12 | 200 | 18 | 0.0374 | 0.984802 |

**Bayes（表 S4）**：
| 训练比例 | 训练样本 | 测试样本 | RMSE | R² |
|---|---|---|---|---|
| 1/12 | 17 | 201 | 0.140528 | 0.85647 |
| 1/4 | 53 | 165 | 0.077236 | 0.958831 |
| 1/2 | 108 | 110 | 0.073269 | 0.962432 |
| 11/12 | 201 | 17 | 0.06772 | 0.961295 |

**GPR（表 S5）**：
| 训练比例 | 训练样本 | 测试样本 | RMSE | R² |
|---|---|---|---|---|
| 1/12 | 18 | 200 | 0.078961 | 0.950387 |
| 1/4 | 53 | 165 | 0.058829 | 0.974705 |
| 1/2 | 109 | 109 | 0.042526 | 0.986414 |
| 11/12 | 200 | 18 | 0.032119 | 0.990233 |

**关键结论**：
- GPR 在**小样本（1/12）**下 RMSE 0.078961、R² 0.950387，远优于 LR（R² 仅 0.330）与 Bayes（R² 0.856），显著优于 SVR（R² 0.903）；
- 训练样本越充足，各方法差距缩小，但 GPR 始终最优（11/12 时 RMSE 0.032119、R² 0.990233）；
- 因此实际工程（退役电池脉冲测试数据有限）应采用 **GPR**。

## 五、对A题建模的启示

### 问题1（退化特征分析与影响因子辨识）
- 用 Fig. S1 的"容量衰减曲线 + 不同倍率充放电曲线"说明退化规律与倍率耦合关系；热测量（Fig. S9）提示**温度是重要影响因子**，可结合 Arrhenius 方程定量描述。
- 分选需求本身（Fig. S2 类型分布、Fig. S3 容量分布离散）即为问题1"批次电池性能差异大"的实证论据。

### 问题2（SOH评估与RUL预测）
- 本文第一步（**容量估计**）与 A 题 SOH 估计目标一致：**GPR 是最优容量/SOH 回归器，尤其适合小样本**——A 题可把 GPR 作为 SOH 估计的基线模型之一，与 LSTM/GRU 时序模型做对比。
- 关键技巧：**用短时脉冲测试数据估计容量**（不用完整循环），是 A 题"快速、低成本检测"需求的直接方案。
- 评价指标直接沿用 **RMSE、R²**。

### 问题3（退役筛选与储能编组多目标优化）——最重要
- **完整范式**：两步学习法 = Step1 分型（标签/历史/参数）+ Step2 分选（回归估计容量 + 聚类分组）。A 题问题3 可直接照搬：
  1. 先用 GPR/K-means 前的回归做容量（SOH）估计；
  2. 再用 K-means 或 GMM 对退役电池聚类分组；
  3. 最后在聚类簇基础上构建多目标优化（NSGA-II + TOPSIS），把 0-1 整数规划的"电池-编组配对"作为决策变量。
- **一致性约束**：二次利用要求"同制造商、同型号、同批次、同性能"——编组约束应包含容量/内阻/OCV 差异阈值、安全阈值、编组数量。
- **异常处理**：聚类结果中 OCV=0/容量=0 的簇（异常电池）与单电池簇（离群点）应剔除或单独处理，避免污染编组——这是本文明确展示的坑。
- **算法选型**：K-means 简单快速；GMM 提供软划分与椭球簇，更鲁棒；可用轮廓系数/肘部法则定簇数 K。

### 问题4（多工况仿真、鲁棒性与工程建议）
- 分选框架（Fig. S12）与自动分拣机（Fig. S13）可支撑"工程落地性"论述——建议给出可量化的检测流程与分选效率指标。
- 热测量说明温度对性能影响，可设计"长期高温、大倍率充放电、批次差异过大"三场景做鲁棒性仿真。
- 灵敏度分析可围绕：训练样本比例（本文 1/12~11/12 全覆盖，是灵敏度分析的天然模板）、聚类簇数 K、一致性阈值等。

## 六、可复用的代码/数据思路

> A题**不提供原始数据**，需自建仿真数据。本文给出了真实退役电池测试流程与数据形态，是构建"退役电池批次"仿真数据的理想模板。

1. **仿真批次数据生成**：
   - 参考 507 个电池的容量分布（Fig. S3），用**正态/混合分布**生成 N 个退役电池的初始容量、OCV、内阻，构造批次差异；
   - 参考表 S1 的簇形态（如 Type 6 簇1 容量 1.186~1.262 Ah、簇3 1.804~1.953 Ah）生成不同类型电池的参数范围；
   - 注入少量异常电池（容量 0 或离群）检验聚类鲁棒性。
2. **脉冲测试特征生成**：按实验流程（1A 充 6min→静置30min→0.5A 10s/静置30s 等 9 档倍率）仿真电压/电流响应，提取响应特征（如压降、极化恢复斜率）作为聚类/回归输入——若嫌复杂，可退化为用"测试容量 + OCV"两个特征。
3. **容量估计（第一步）代码**：
   - `sklearn.linear_model.LinearRegression`、`sklearn.svm.SVR`、`sklearn.linear_model.BayesianRidge`、`sklearn.gaussian_process.GaussianProcessRegressor`（推荐，配 RBF 核）；
   - 按训练比例 1/12、1/4、1/2、2/3、11/12 做学习曲线，报告 RMSE 与 R²（复现图 S11）。
4. **聚类（第二步）代码**：
   - K-means：`sklearn.cluster.KMeans`；GMM：`sklearn.mixture.GaussianMixture`；
   - 特征标准化（StandardScaler）→ 肘部法则/轮廓系数选 K → 聚类 → 输出各簇 OCV、容量范围表（仿表 S1）；
   - 对异常簇（样本数极少或特征异常）做剔除逻辑。
5. **编组优化扩展**：聚类结果 → 0-1 整数规划/NSGA-II 多目标（一致性、安全、成本、收益），得到帕累托前沿后再用 TOPSIS 选折中方案。
6. **可视化**：复现 Fig. S3（容量分布）、Fig. S10（聚类散点）、Fig. S11（RMSE/R² 随训练比例变化）——这些图与 A 题要求的图表高度契合。
