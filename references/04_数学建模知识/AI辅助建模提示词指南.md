## 一、AI在数学建模中的定位

**核心原则：AI是加速器，不是替代品。**
- AI负责提速（分析赛题、写代码框架、画图、润色）；
- 你负责把关（判断对不对、解释清不清、结果对不对）；
- AI生成的任何内容必须逐行看过、能解释清楚——答辩答不上来直接露馅。

### AI能做什么 vs 不能做什么

| AI擅长的（让它做，你审查） | AI不擅长的（必须你做） |
|---------------------------|------------------------|
| 快速提取题目关键信息和数据要求 | 判断模型是否合理、假设是否恰当 |
| 生成Python/LaTeX代码框架 | 理解题目深层含义和隐含约束 |
| 编写matplotlib绘图代码 | 解释"为什么选这个模型" |
| 批量数据清洗和转换代码 | 创新性建模思路和方法组合 |
| 检查论文语法错误和格式 | 保证结果正确性（AI经常算错） |
| 中英文翻译和文字润色 | 写摘要（AI写的摘要一眼假，直接扣分） |

## 二、AI+数学建模四阶段万能提示词框架

> 出自《（最新版）AI+数学建模万能建模求解提示词》，是"一题通用"的总框架。每一阶段都要求AI"图片生成失败请重新生成"，把流程图一并做出来。

### 第一阶段：赛题深度结构化分析

```
逐句拆解题目，用表格划分：背景信息、核心子问题、已知条件、参数数据、约束规则、
行业/物理限定；标注题目遵循的核心原理（物理定律/运筹规则/统计规律/生态机理/社会规则）。
拆分每一小问，明确每一问直接目标、隐含铺垫目标、输出要求（数值/公式/最优方案/专业图表），
梳理各小问前后递进逻辑关系。
对每一问单独题型归类：机理分析类/预测建模类/评价分析类/优化决策类/统计分析类/网络构建类，
并写明判定依据。
生成思维导图梳理各小问之间的逻辑关系，清晰美观、配色精美、逻辑对接一目了然，图片直接生成！
注意！图片生成失败，请帮我重新生成该阶段全部图片！
```

### 第二阶段：各小问模型构建与创新设计

```
为题目的每一问构建创新型冲奖模型，并给出模型名称；仅限三类创新方向任选其一，禁止无意义套模型：
①算法改进创新 ②跨领域模型迁移创新 ③多模型融合组合创新。
每个模型必须完整包含5项固定内容：
①核心原理：用通俗语言结合本题场景解读；
②场景适配性：明确适配本题数据、约束、目标的原因；
③真实创新点：和传统模型差异、对解题精度与实用性的实际提升；
④模型局限性+规避方案：列明误差来源、假设缺陷，配套敏感性分析、鲁棒性检验、数据校准等修正手段；
⑤建模核心过程：严格按「场景抽象→变量定义→模型构建→数据适配→求解迭代→结果验证」完整描述。
结合上述分析生成汇总表，表头：问题序号、问题描述、整体解题思路、建模模型、理由和创新点。
最后分别生成每一问的建模流程图（配色美观，矩形+箭头，只体现核心步骤，不要过长）！
```

### 第三阶段：数据全自动获取与预处理

```
若存在上传的附件数据，请将本地上传数据进行读取处理，使后续模型求解和代码编写不依赖本地路径上传。
先判定数据情况：题目自带数据则梳理维度、字段、单位、数据类型；无自带数据则自主检索权威公开数据，
明确标注来源；核心缺失参数按场景逻辑合理假设并写明依据。
若无需数据处理可直接说明"无需数据预处理"，不执行后续操作。
需要预处理时：严格按数据类型适配预处理方法（缺失值填充、异常值检测修正/删除、标准化归一化、
One-Hot/标签编码、复杂数据特征提取），每一步必须写明选用该方法的场景依据。
必须输出Python/Matlab可选的完整可运行代码：不需要本地路径、逐行详细注释、异常捕获、
读取失败兼容逻辑，并自动运行给出完整处理结果。
输出处理后数据前10行、后5行；保存为CSV/MAT通用格式；给出数据完整性校验方法；
撰写可直接放入论文的数据预处理完整结论。
生成数据预处理前、后双可视化绘图，图表美观合规！
```

### 第四阶段：模型建立—求解—检验—结果分析（每小问独立四模块）

```
请帮我生成第【X】小问完整的模型建立—求解—检验—结果分析（每小问独立四模块，缺一不可）

模块1：模型建立与公式推导
- 变量定义三线表：区分决策变量/中间变量/目标变量/已知参数/待校准参数，标注类型、单位、取值范围、现实含义
- 3-5条核心模型假设：每条按「假设内容+设立依据+对模型的影响」撰写，禁止无依据凭空假设
- 详细公式推导：每模型至少10个左右公式，规范编号，每一步标注逻辑依据，符号统一
- 生成关键流程图（简洁，突出重点，配色丰富）

模块2：模型求解与结果呈现
- 明确求解软件、核心库/工具箱、完整求解步骤
- 可直接运行的完整代码（不依赖本地路径、逐行注释、异常捕获、自动运行出结果）
- 量化输出数值结果，结合赛题背景专业解读
- 关键结果生成竞赛级图表（折线/柱状/热力/拓扑/拟合图；必备：标题、坐标轴带单位、图例、30-50字专业图注）

模块3：模型检验与验证
- 有效性检验：按模型类型选用R²、MSE、残差分析、交叉验证、约束满足度等指标量化
- 鲁棒性分析：核心参数±10%波动、加入合理噪声，测算结果偏差幅度
- 模型对比检验：横向对比基础模型与创新模型的精度、稳定性、场景适配性，凸显创新价值

模块4：结果深度分析与讨论（三层结构）
①基础数值分析：解读结果现实意义、量化效益与方案价值；
②深层机理分析：验证结果符合物理规律、约束条件与现实逻辑，完成核心参数敏感性分析；
③应用延伸分析：结合行业背景提炼结论，给出实际调度/决策/预测/规划的落地参考。

注意！图片生成失败，请帮我重新生成该阶段全部图片！
必做！接下来依次进行剩余各小问的建模和结果分析即可！
```

## 三、八步解题提示词（数学建模问题求解AI提示词）

> 出自《数学建模问题求解AI提示词.docx》，共8个阶段，适合小问逐个击破。

### 第0步 前置信息说明（先喂给AI的"人设"）

```
我是数学建模国赛参赛选手，需解决以下题目：【粘贴完整题目文本及附件说明】
团队情况：□ 零编程基础 □ 擅长编程语言（如Python/Matlab） □ 有基础建模经验 □ 首次参赛
需求重点：□ 模型创新性 □ 代码可执行性 □ 结果可视化 □ 论文写作素材（分析/结论）
获奖目标：□ 国家级一等奖 □ 国家级二等奖 □ 省级一等奖
建模难度：□ 难度较大 □ 难度适中 □ 较为简单
```

### 第一步 题目分析阶段
- 逐句解析题目，区分「背景信息」「核心问题」「已知条件」「约束条件」（表格分列）。
- 明确小问划分：列出各小问「直接目标」和「隐含目标」（如表面求方案，实际需验证可行性）。
- 逻辑关系梳理：思维导图展示各小问关联（如小问2是小问3的前提）、参数依赖关系。
- 题型分类：判断各小问属于优化类（单/多目标）/预测类（时序/回归）/评价类（指标体系）/机理分析类，并说明依据。

### 第二步 模型选择阶段
针对每个小问推荐2种模型方案：
- 方案1（基础适配）：经典模型+改进点（如「灰色预测GM(1,1)」→「滚动窗口GM(1,1)-马尔可夫链修正」）
- 方案2（创新融合）：跨领域模型组合（如「图神经网络GNN+强化学习」解决路径优化）
每种模型说明：核心原理（1段通俗语言）、适配性、创新点、局限性、可视化流程（含决策点）。

### 第三步 数据处理阶段
- 缺失值：均值/插值/KNN填充，说明依据，给出处理后数据。
- 异常值：Z-score法/IQR法检测，说明保留/修正/删除理由，附箱线图。
- 转换处理：说明标准化/归一化必要性，给出转换公式及处理后数据。
- 数据补充：区分「必须补充」（政策参数）与「可选补充」（提升精度外部数据），推荐获取途径（国家统计局、Kaggle），基于合理假设生成补充数据（附依据）。

### 第四步 模型建立阶段
- 变量定义表格：决策变量/中间变量/目标变量，标注类型、单位、约束范围（如x₁∈[0,100]）。
- 假设条件3-5个（含合理性说明）。
- 分步推导核心公式，每步标注物理意义（如"式(3)表示成本最小化约束"）。
- 建模流程图：「变量→公式→约束→目标」逻辑链。

### 第五步 模型求解阶段
- 求解步骤：「数据输入→参数初始化→模型调用→结果输出」，标注注意事项。
- 代码实现：零编程基础→提供可直接运行代码（标注依赖库及安装命令、可视化模块、关键行注释"为何这么写"）；指定语言→符合语言规范、含异常处理。
- 可视化分析：根据结果类型选图表（优化→柱状图对比，预测→折线图趋势），含标题/坐标轴标签/图例，图下标注关键结论（如"图3显示方案2成本比方案1低15%"）。

### 第六步 结果分析阶段
- 基础分析：数值解读（物理意义）、统计描述（均值/方差/极值，如"误差集中±5%"）。
- 深层分析：关联性（结果与约束匹配度）、敏感性（参数k增加10%结果偏差2%）、实际意义（企业年收益提升8%）。

### 第七步 模型检验与改进阶段
- 有效性检验：按模型类型选指标（预测用RMSE，评价用Kappa系数），提供检验代码（如5折交叉验证），输出结果（如"平均RMSE=2.3<阈值5，模型有效"）。
- 改进方向：误差大→增加数据/引入非线性/多模型集成；假设不合理→放松假设引入随机扰动。
- 鲁棒性分析：输入数据加10%噪声，观察结果变化幅度。

## 四、论文撰写AI提示词

> 出自《数学建模论文撰写AI提示词.docx》。分"初稿撰写阶段"+"论文优化阶段"两大部分。

### 4.1 初稿撰写阶段（5个模块）

**基础指令（人设）**：
```
我是一名参加数学建模竞赛的同学，我想要拿到这次比赛的一等奖，请基于已完成的各小问
问题分析、模型建立、求解及检验结果，按以下要求完成论文撰写与优化全流程。
```

**模块一：题目、摘要和关键词**
- 题目：采用"基于XXX模型/方法/理论的XXX问题研究"格式，精准体现核心模型与研究对象。
- 摘要："问题-方法-结果-结论"结构，800-1000字，不超过1页，无图表。明确背景、关键方法、核心结果（具体数据、误差值）、模型优势。
- 关键词：3-5个，包含核心模型名称、研究问题主题词。

**模块二：问题重述、问题分析、模型假设、符号说明**
- 问题重述：原创语言梳理背景/核心目标/约束，严禁复制原题，提炼2-3个子问题，结合近3-5年文献深化理解。
- 问题分析："总-分"结构，每小问开头"问题X分析"，呈现①关键矛盾点②解题思路框架③核心步骤拆解，仅思路不涉及结果，单页内。可附流程图描述。
- 模型假设：3-5条，每条含①假设内容②合理性依据（如"根据3σ原则异常值占比低于0.5%"）③对模型的影响。
- 符号说明：三线表（符号、含义、单位）。

**模块三：模型建立、模型求解及结果分析**（每小问）
- 模型构建：说明模型原理、建模步骤、核心公式（含推导逻辑）。
- 求解方法：明确求解工具（MATLAB/Python库）、步骤、关键结果；文字描述图表核心信息。
- 结果分析：①基础分析②深层分析（敏感性，如"因素A影响权重0.35"）③直接回应问题。
- 模型检验：检验方法（残差检验/显著性检验）、步骤、结果（如"后验差比C=0.28<0.35，小误差概率P=0.96>0.95，模型精度一级"）。

**模块四：模型评价、参考文献、附录**
- 模型评价：优点3-5条（创新性/适用性/效率，每条有数据支撑）；缺点2-3条（假设限制/数据依赖/可扩展性局限），避免泛泛而谈。
- 参考文献：5-10条近5年文献，期刊[J]/专著[M]，中外结合，优先核心期刊。
- 附录：完整程序代码（标注语言版本、关键注释）、中间计算结果、处理后数据、补充图表。

**模块五：论文整合汇总**
```
结合上面的所有内容，将所有生成的模块进行整合，撰写一篇不低于【页数要求】不超过【页数要求】的
数学建模论文，如果页数不够请进行补全。
要求论文各模块内容包括：题目、摘要、关键词、问题重述、问题分析、模型假设、符号说明、
各小问模型建立与求解、结果分析及模型检验、模型优缺点评价、参考文献和附录等，得到数模论文初稿。
```

### 4.2 论文优化阶段（3个专项）

**（一）初稿全面优化指令**
- 文字校对：错别字、语病（"的/得/地"误用、句子成分残缺）。
- 逻辑梳理：填补逻辑断层（"模型选择依据"与"问题特征"衔接）。
- 格式规范：统一字体字号、图表编号（图1-1）、公式编号（(2.3)）、三线表。
- 内容精炼：删冗余、补缺失（公式参数物理意义）。

**（二）摘要专项优化**
- 篇幅：800-1000字，不超过1页。
- 要素完整性：研究背景、问题核心、模型方法、关键结果、主要结论。
- 逻辑：按"背景→问题→方法→结果→结论"排序。
- 专业准确性：修正术语错误、"结果较好"改为"准确率达91.3%"。
- 亮点突出：标注创新点（如"融合XX的改进模型，求解速度提升30%"）。

**（三）摘要格式优化（O奖标准）**
- 引言/背景（3-5行）：概括领域现状与问题重要性。
- 正文段落：每段以"针对问题X"开头，说明①具体内容②采用方法（如"构建多目标整数规划模型，通过NSGA-Ⅱ算法求解"）③核心结果（如"Pareto最优解集中方案A产能利用率92%，成本降低8%"）。
- 收尾（2-3行）：总结创新点与应用价值。

## 六、AI使用注意事项（2026规定与红线）

### 6.1 不可逾越的红线

1. **不用AI写摘要**——AI摘要模板味重、空洞，评委会直接识别扣分。
2. **不直接复制AI代码**——逐行看懂、本地跑通、用假数据验证。
3. **不用AI查文献**——AI会编造不存在的论文和作者名，文献只能去知网/Google Scholar。
4. **AI生成内容占论文比例不超30%**——核心建模思路和关键推导必须自己完成。
5. **所有AI生成的结果必须验证**——AI可以算错、可以用错公式。

### 6.2 代码生成的正确姿势

原则：**不要让AI从零写一个你不知道怎么写的程序。正确做法是——你知道程序的逻辑步骤，让AI填空。**

1. 你先设计函数接口：函数名、参数、返回值、处理步骤写清楚；
2. AI生成实现代码（把接口描述给AI，让它填充实现）；
3. 你逐行审查：每行代码看懂，拿假数据先跑一遍；
4. 对比标准结果：能手动算的简单情况与AI输出对比。

**AI代码三大陷阱（必查）**：
1. AI会编造不存在的参数（如sklearn某函数没有某参数）——每个不熟悉参数去官方文档确认；
2. AI会写逻辑正确但效率极差的代码（循环里反复创建大数组）——长数据要测性能；
3. AI会"不小心"修改关键逻辑——只复制需要的改动，不要整段替换。

### 6.3 AI辅助各环节的具体用法

| 环节 | 正确做法 |
|------|----------|
| **赛题分析** | 第一步10分钟不用AI通读；第二步AI辅助深度分析（每人/每题10-15分钟）；第三步**两个AI交叉验证**；第四步定题后细化方案 |
| **数据收集** | 明确告诉AI领域/时间范围/颗粒度；拿到数据后抽几个点去官方统计网站核对；AI给的数据说明要自己核对每句话 |
| **模型选择** | 让AI横向对比候选模型（表格：适用场景/数据要求/可解释性/训练速度/缺失值容忍度）；确定后要带注释的代码模板，关键参数和数据加载留空自己填 |
| **代码调试** | 分段验证：每完成一个功能模块让AI检查；主动加鲁棒性处理（缺失值中位数填充、3σ剔除） |
| **绘图** | 先用AI生成初版代码→运行看效果→反馈迭代2-3轮；plt.savefig指定dpi=150，文件名用中文 |
| **论文润色** | 先自己写段落→给AI"请检查语法错误、术语不一致、表达不清，标注建议修改，但不要改我的意思，不要添加我没有的信息"→逐条审查AI建议 |
| **英文写作（美赛）** | 中文初稿→分句/分短段落翻译，关键术语先确认（如"过拟合"在英文论文中如何表达），避免整段翻译产生中式英语 |

### 6.4 三重验证（防AI误导核心步骤）

1. **数据验证**：核对AI收集的数据是否有不合逻辑的值（负数面积、超100%比例）；让AI说出每个字段的单位和取值范围，人工核对。
2. **逻辑一致性验证**：把AI生成的关键段落连起来读，检查前后矛盾（前面说准确率92%，后面说主要误差是数据不足，是否有冲突）。
3. **反事实测试**：对AI生成的模型结果做小范围扰动（微调几个输入），看输出变化是否符合预期，异常说明模型有问题。

### 6.7 高效使用AI的6条核心忠告

1. **把问题吃透比啥都强**：AI能算结果但搞不懂题目藏着的"坑"，先自己拆明白关键数据、干扰项，再让AI帮忙，别被它带偏。
2. **数据处理别偷懒**：拿到数据先自己筛（明显错的、重复的、藏着的规律），这步做好AI算的才靠谱，很多人忽略这步。
3. **挑"冷门"难题突破**：简单模型AI玩得溜，但动态系统（疫情加防控）、多目标平衡（又低成本又高效率）这类需要把实际问题转成数学公式的活，AI不如人灵活，多练这类题容易出彩。
4. **团队别各干各的**：编程的得懂模型逻辑，写论文的得明白模型咋来的，有人能兼顾两块沟通更顺。
5. **AI是助手不是爹**：让AI查资料、搭基础模型、排版没问题，但它推荐的模型你得想清楚"为啥用这个""和题目匹配吗"，结果出来要分析"合理吗""有啥改进空间"——这些思考过程才是评委看重的。
6. **论文写得让人看懂**：别堆公式，把思路讲明白——"发现了啥问题、用了啥方法解决、结果说明啥"，图表做漂亮、逻辑理清楚，让评委一眼看到亮点。

## 七、提示词使用技巧总结

1. **角色设定先行**：所有提示词开头先给AI"人设"（如"你是数学建模竞赛教练/资深数模专家/一等奖冲刺选手"），大幅提升输出质量。
2. **前置信息喂足**：题目全文+团队情况+获奖目标+难度，AI才知道往哪个方向使劲。
3. **分阶段、分模块提问**：不要一次让AI写完整篇论文，按"分析→建模→求解→检验→写作"逐步推进。
4. **要求输出结构化**：表格、分点、流程图，便于直接转化为论文素材。
5. **强制"数据支撑+量化"**：要求AI每个结论带具体数字（误差、百分比、得分），杜绝"效果良好"式空话。
6. **交叉验证**：同一问题给两个不同AI，结论一致才可靠。
7. **人工复核优先级**：真实结果优先 > 逻辑一致优先 > 人工复核优先（AI助力数模国赛核心原则）。
