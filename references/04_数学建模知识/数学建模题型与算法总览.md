## 一、国赛入门（CUMCM）

### 1.1 比赛概况

- 全称：全国大学生数学建模竞赛（CUMCM），由中国工业与应用数学学会主办，始于1992年，每年9月举行，是世界上规模最大的数学建模竞赛。
- 赛制：**三人组队 + 三天（74小时）+ 一篇论文**。论文是唯一评审依据，不需要现场答辩（国一除外）。
- 2024年参赛队伍超6万支（约18万学生）。
- 典型队伍组合：数学/统计 + 计算机 + 工程/经管。

### 1.2 题型与选题策略

每年出 **A/B/C/D/E 五道题**，任选一题。题型倾向与典型方法如下：

| 题号 | 倾向 | 典型场景 | 涉及方法 |
|------|------|----------|----------|
| A题 | 物理/工程 | 热传导、应力分析、天线设计、CT成像、烟幕干扰弹 | 微分方程、有限元、数值模拟 |
| B题 | 社会/经济 | 交通优化、资源分配、政策评估、调度 | 优化模型、图论、博弈论 |
| C题 | 数据/统计 | 分类识别、预测、综合评价、异常检测 | 机器学习、统计建模、数据分析 |
| D题 | 优化/运筹 | 路径规划、生产调度、库存管理 | 线性/整数规划、启发式算法 |
| E题 | 综合/交叉 | 环境评估、生态建模、传染病、能源 | 机理 + 数据混合建模 |

**选题策略（老哥经验）**：
- C题（数据题）选的人最多（约40%），门槛低但区分度小——难拿国一。
- A/B题选的人相对少（各约20%-25%），区分度大——做得好容易冲国奖，但难度高。
- 队伍有物理/工科背景 → 优先 A/B 题；纯数学/统计/计算机 → C题最稳；跨学科组合 → B 或 E 题。

### 1.3 出题规律（近10年）

1. **三年不重复，但有周期**：同领域题目不会连续出现，每3-4年类似题型回归。
2. **热点映射**：当年社会/科技热点大概率进赛题（2020新冠→传染/隔离；2022碳中和→能源优化；2024→AI/大数据）。
3. **C题年年有**：自2015年固定为大数据/统计建模方向，每年必有一道纯数据题（给Excel/CSV附件）。
4. **每道题通常3-4个小问**：递进逻辑——第1问简单（入门/验证），第2-3问复杂，第4问要求模型改进或灵敏度分析。**分问计分**，前两问做不完不影响后两问。

### 1.4 获奖率与评奖机制

| 奖项 | 大致比例 | 说明 |
|------|----------|------|
| 省一等奖 | 约8% | 前10%-15%送全国评审 |
| 省二等奖 | 约15% | 直接确定 |
| 省三等奖 | 约20% | 直接确定 |
| 成功参赛奖 | 约57% | 提交有效论文即可获得 |
| 全国一等奖 | 约0.5%-1% | 需答辩 |
| 全国二等奖 | 约2%-3% | 不需答辩 |

- 每100支队约3支拿国奖。
- 省级初筛硬性：**全文重复率 > 25% 或代码重复率 > 50% → 淘汰**。

**评分核心维度（按权重）**：
1. 模型合理性 30%-40%：模型是否贴合问题特征？假设是否合理？
2. 求解正确性 25%-30%：结果是否正确？是否完成所有小问？
3. 论文表达 20%-25%：结构清晰？逻辑通顺？图表规范？
4. 创新性 10%-15%：独到思路？模型改进？

> 评委最看重：**为什么选这个模型、数据怎么处理、假设合不合理、灵敏度分析做了没有、结论有没有数据支撑**。不是用了多高深的算法。

## 二、四大题型分类与选型口诀

竞赛问题本质可归为 **优化类 / 预测类 / 评价类 / 机理分析类** 四大主流题型。

### 2.1 题型区分（看问句关键词）

| 题型 | 问句关键词 | 核心特征 | 数据要求 |
|------|-----------|----------|----------|
| **优化题** | 最优方案、最大、最小、如何安排、调度、分配、路径 | 一定有**决策变量**，有明确目标+约束 | 参数/约束条件 |
| **评价题** | 评估、比较、排序、优劣、综合水平、绩效、选址 | 研究对象**≥2个备选方案**，多指标冲突 | 指标数据 |
| **预测题** | 预估、预测、未来走势、趋势、估计、预报 | 输入**历史数据**，输出未来数值/趋势 | 时序或面板数据 |
| **机理题** | 机理、规律、演化过程、传播、扩散、动态 | 需要**物理/工程原理建立方程**，数据用来反演参数 | 可少，重领域知识 |

**四大题型出现频率（讲义2统计）**：
- 优化类 约40%（出现频率最高）
- 评价类 约25%
- 预测类 约20%
- 机理分析/其他 约15%

### 2.2 四大题型选型口诀（速记）

```
优化题：能小数线性→LP；必须整数→IP；选或不选→0-1；平方乘积曲线→NLP；又要赚钱又省钱→多目标；排列组合找最优→组合优化（GA/PSO/SA）
评价题：无数据靠经验→AHP；有数据要公正→熵权法；比优劣排顺序→TOPSIS；评等级很模糊→模糊评价；数据大求精准→机器学习
预测题：4-10个点→灰色GM(1,1)；≥30个时序点→ARIMA；有多个特征→回归；数据>10000→神经网络/LSTM
机理题：找原因析影响→因果归因；物理变高精度→微分方程；拆系统理逻辑→结构机理；看反馈长期演化→系统动力学
```

## 三、各题型常用模型清单

### 3.1 优化类模型清单

| 模型 | 适用条件 | 解质量 | 一句话 |
|------|----------|--------|--------|
| 线性规划 LP | 目标+约束全线性，变量连续 | 精确最优 | 能线性化就线性化 |
| 整数规划 IP | 含整数/0-1变量（人数、件数） | 精确最优 | 选址、指派问题 |
| 0-1规划 | 变量只能0/1（选/不选、开/关） | 精确最优 | 项目筛选、选址、线路取舍，**国赛高频** |
| 非线性规划 NLP | 目标/约束含平方、乘积、指数 | 近似（局部最优） | 物理仿真、参数反演（2025A烟幕优化、B题参数拟合） |
| 多目标规划 | 两个及以上冲突目标 | Pareto折中 | 加权求和/层次/AHP/帕累托最优解 |
| 组合优化 | 离散方案组合择优（TSP、排程） | 近似最优 | 靠GA/PSO/SA等智能算法 |
| 遗传算法 GA | 非线性/非凸/方案组合复杂 | 近似最优 | 万能但慢 |
| 粒子群 PSO | 连续优化 | 近似最优 | 收敛比GA快 |
| 模拟退火 SA | 易陷入局部最优 | 近似最优 | 允许"先变差"跳出局部最优 |
| 动态规划 DP | 多阶段决策、最优子结构 | 精确 | 状态转移方程（2020B穿越沙漠） |
| 图论/最短路径 | 交通网络、节点连通 | 精确 | Dijkstra（单源）/Floyd（多源） |
| 排队论 M/M/c | 等待时间、服务台数量 | 解析 | 机场出租车、调度问题 |
| 蒙特卡洛模拟 | 不确定性过程随机抽样 | 统计逼近 | 概率验证、扰动场景 |

**智能优化通用框架**：初始化 → 评价 → 更新 → 停止。

**"先常规后智能"原则（重要）**：
1. 先尝试常规优化模型（LP/NLP/IP），看能否求解；
2. 求解器报错或计算时间过长，再考虑智能算法；
3. 用智能算法时论文必须说明："由于该问题变量规模达到XXX，精确求解在有限时间内难以完成，故采用启发式算法寻找近似最优解"。

### 3.2 预测类模型清单

| 模型 | 数据量 | 数据类型 | 一句话 |
|------|--------|----------|--------|
| 线性回归 | 不限 | 有特征+标签 | 最简单的预测基线 |
| 灰色预测 GM(1,1) | 4-10个点 | 近似指数增长/单调序列 | 数据极少时的救命稻草 |
| ARIMA | ≥30个时序点 | 纯时间序列（需平稳） | 时序预测标配 |
| 指数平滑/移动平均 | ≥30 | 趋势平稳 | 简单基线 |
| Prophet | 大量 | 时序（含节假日效应） | 可加性模型 |
| 神经网络/BP | 大量 | 任意 | 数据多用不完时选它 |
| LSTM | 大量 | 长程依赖时序 | 时序深度学习经典 |
| Transformer | 大量 | 时序/NLP | 自注意力，并行快 |
| 随机森林回归/XGBoost | 不限 | 多特征回归 | 机器学习集成预测 |
| 马尔可夫预测 | 序列 | 状态转移 | 预测状态概率分布、等级变化 |

**时间序列三要素**：趋势 Trend、季节性 Seasonality、随机性/噪声 Noise。

**ARIMA(p,d,q)**：p=自回归阶数，d=差分阶数（使非平稳变平稳），q=滑动平均阶数。建模步骤：ADF平稳性检验 → ACF/PACF定阶 → 参数估计（最大似然）→ 残差白噪声检验（Ljung-Box）→ 预测。

**预测选型**：4-10个点 → 灰色预测；≥30个时序点 → ARIMA；有多个特征 → 回归；数据>10000 → 神经网络。

### 3.3 评价类模型清单

| 模型 | 权重来源 | 数据要求 | 一句话 |
|------|----------|----------|--------|
| AHP层次分析法 | 专家打分（主观） | 指标≤9个，可无数据 | 两两比较，一致性检验 |
| 熵权法 EWM | 数据离散度（客观） | 数据完整 | 差异越大权重越高 |
| TOPSIS | 搭配主/客观权重 | 有数据可量化 | 离最优最近、离最劣最远 |
| 模糊综合评价 | 隶属度 | 指标模糊定性 | 把"好中差"变成数 |
| PCA/因子分析 | 降维 | 指标多、信息重复 | 提取主成分 |
| 灰色关联分析 | 序列几何接近度 | 样本少、信息不完整 | 关联度排序 |
| DEA数据包络 | 效率 | 多投入多产出 | 效率评价 |
| 机器学习评价（RF/SVM/BP） | 自动学习 | 大量样本 | 高精度分级评价 |
| 组合评价 | 主客观组合 | 综合 | **竞赛最推荐** |

**评价类高分组合**：
1. 基础稳妥：AHP + TOPSIS（少数据通用）
2. 严谨高分：熵权法 + TOPSIS（多数据首选）→ 即 **AHP-EWM-TOPSIS 组合**
3. 定性专属：AHP/熵权 + 模糊综合评价
4. 创新进阶：机器学习 + 传统算法对比验证

**组合权重公式**：`w = α·w_a + (1-α)·w_e`，其中 w_a 为 AHP 主观权重，w_e 为熵权法客观权重。无特别理由取 α=0.5；专家经验可靠取0.6-0.7；数据充分取0.3-0.4。

### 3.4 机理分析类模型清单

| 模型 | 适用场景 | 一句话 |
|------|----------|--------|
| 微分方程（ODE/PDE） | 连续变化（传染病、温度、传热） | 经典严谨，需推导，国赛A/B题王牌 |
| 差分方程 | 离散时间步（种群代际） | 微分方程的离散版 |
| 元胞自动机 | 局部规则→全局涌现（森林火灾） | 不需方程，定义规则就跑 |
| 系统动力学 SD | 存量-流量-反馈回路、长期宏观演化 | 正/负反馈，宏观趋势 |
| 因果归因分析 | 找原因、量化贡献度 | 偏相关、灰色关联、SHAP、回归系数 |
| 结构机理分析 | 拆系统、理层级、明逻辑 | 结构拆解图、框架拓扑 |
| 马尔可夫/蒙特卡洛 | 状态转移、不确定性传播 | 概率仿真 |

**机理模型四大步骤**：分析机理（找存量+流量，画存量-流量图）→ 建立方程（微分/差分/元胞规则）→ 数值求解（odeint/solve_ivp）→ 参数敏感性（有数据最小二乘拟合，无数据查文献取范围）。

**SIR 传染病模型**（最经典机理案例）：
```
dS/dt = -β·S·I/N
dI/dt = β·S·I/N - γ·I
dR/dt = γ·I
基本再生数 R0 = β/γ（R0>1扩散，R0<1消亡）
群体免疫阈值：S < N/R0 时新增感染开始下降
```

### 3.5 分类/聚类模型清单（C题高频）

**分类模型**（有标注）：

| 模型 | 样本量 | 特征数 | 可解释 | 一句话 |
|------|--------|--------|--------|--------|
| 逻辑回归 | 不限 | 少 | 高 | 基线首选，交叉熵+梯度下降 |
| KNN | 小 | 中 | 中 | 不需训练，直接投票 |
| SVM | 小中 | 多 | 低 | 小样本高维之王，需标准化 |
| 随机森林 | 不限 | 不限 | 中 | 万能，自带特征重要性 |
| XGBoost/LightGBM | 大 | 多 | 中 | 集成提升，精度高 |

**聚类模型**（无标注）：

| 模型 | 需预设K | 非球形 | 一句话 |
|------|---------|--------|--------|
| K-means | 是 | 否 | 最简单高效，数据球形就选它 |
| 层次聚类 | 可后选 | 可以 | 画树状图选K，适合小数据 |
| DBSCAN | 否 | 是 | 自动发现聚类数，识别噪声 |

**聚类定K**：肘部法则（SSE拐点）+ 轮廓系数（[-1,1]越大越好）；两者不一致以轮廓系数为准。**距离类算法聚类前必须标准化**（Z-score或min-max）。

### 4.4 A 题方向（物理/工程）

A 题以微分方程机理建模为骨架，常见手段：
- 热传导/扩散：傅里叶定律 → PDE → 有限差分/有限元/有限体积离散求解。
- 运动/动力学：牛顿定律/拉格朗日方程 → ODE → ode45/solve_ivp。
- 参数反演：有实测数据时用最小二乘/贝叶斯反演/PSO 校准模型参数。
- 优化耦合：机理正问题作求解器 + 外层优化（二分搜索、遗传算法）确定最优参数（如热防护服厚度优化）。
- 蒙特卡洛：材料参数/环境波动不确定性传播分析。

**典型A题解题链条**（以热传导防护服为例）：
1. 问题一：正问题——给定参数求解温度分布（FDM/Crank-Nicolson）。
2. 问题二：反问题——以厚度为决策变量，皮肤温度≤44℃为约束，二分搜索最小总厚度。
3. 问题三：鲁棒性——环境温度/导热率±波动下12种场景重算 + 蒙特卡洛1000次 → 给出安全裕度。

## 五、七步解题法（从读题到交卷）

> 综合讲义1的模型章流程（5步/4步解题流程）与全流程速成课，国赛通用解题流程归纳为七步：

```
第1步 赛题分析：逐句读题，区分背景信息/核心问题/已知条件/约束条件；
        判断每个小问的题型（优化/预测/评价/机理），梳理小问间递进关系；
        当天20:00前必须定题。
第2步 数据预处理：缺失值（删除/均值/插值/模型填补）+ 异常值（3σ/Z-score/IQR）+ 标准化；
        所有距离类/机器学习算法必须先标准化。
第3步 模型选择：先出"基线模型"（最简单能用），再考虑改进/创新；
        基础保分模型 + 创新冲奖模型双方案对比。
第4步 模型建立：变量定义（三线表）→ 假设（3-5条，含依据与影响）→ 公式推导（编号规范）。
第5步 模型求解：先常规（LP/NLP/IP精确求解器），搞不定再智能算法（GA/PSO/SA）；
        代码分段验证，先假数据跑通再上真实数据。
第6步 结果分析与检验：基础分析 + 深层分析（敏感性/特征重要性）；
        必做灵敏度分析（参数±10%）、误差分析（MAPE/RMSE）、模型对比。
第7步 论文写作：边做边写，第一天晚上就开写；
        摘要正文全部完成后写，字斟句酌（详见论文写作规范文档）。
```

**三条生存法则**：
1. **第一天晚上就开始写论文**（引言、问题重述、框架可以先写）——不等模型全做完再动笔。
2. **不等队友**：建模手给大致方案 → 编程手立刻用假数据写代码框架 → 写手立刻写文字框架，三人并行不串联。
3. **先做出来，再做好**：每问先用最简单方法出结果（基线模型），全做完有余力再回来优化。评委看的是"做完全部问题"，不是"第一问用了多高深模型"。

## 六、各题型标准解题流程（速查）

### 6.1 评价类五步流程
1. 建指标体系（查文献定维度一级 + 拆可量化二级，画层次图）
2. 数据预处理（正向化：成本型取倒数统一"越大越好" + 标准化 min-max/z-score）
3. 定权重（AHP主观 / 熵权客观 / 组合=主观×客观取平均最稳妥）
4. 算得分（TOPSIS：加权标准化 → 最优/最劣距离 → 综合得分 Ci = D⁻/(D⁺+D⁻)）
5. 灵敏度分析（必做：权重±10%看排名是否变化）

**评价常见坑**：忘正向化（排名反过来）、AHP不检验一致性（CR>0.1必须调）、权重接近0删指标、缺灵敏度分析。

### 6.2 分类问题五步流程
1. 预处理（缺失值 + One-Hot编码 + 标准化 + 7:3划分训练测试）
2. 选模型+训练（逻辑回归跑基线，随机森林对比）
3. 评估（准确率/精确率/召回率/F1 + 混淆矩阵 + ROC/AUC；**类别不平衡用F1/AUC不用准确率**）
4. 特征重要性（随机森林 feature_importances_）
5. 模型对比（表格对比2-3个模型性能，说明选型理由）

### 6.3 聚类问题四步流程
1. 标准化（必做，否则大数值特征绑架结果）
2. 定K（肘部法则SSE拐点 + 轮廓系数，不一致以轮廓系数为准）
3. 聚类+可视化（n_init=10；高维PCA降维画散点；雷达图画像）
4. 聚类结果解释（最关键的：每簇业务含义 + 给簇起"人设名" + 差异化策略建议）

### 6.4 预测问题五步流程
1. 判断类型（时序→ARIMA/灰色；多特征→回归）
2. 预处理（时序：ADF平稳性检验，不平稳差分；回归：标准化+划分）
3. 建模（ARIMA用ACF/PACF定阶；回归线性→Ridge/Lasso；灰色仅一个参数α）
4. 评估（回归：MSE/MAE/R²；时序：MAPE/RMSE；必画预测vs真实图）
5. 预测+区间（点值+置信区间90%/95%是加分项）

### 6.5 优化问题四步流程
1. 三要素建模（决策变量 + 目标函数 + 约束条件）
2. 判断类型（全线性→LP；含0-1→整数规划；非线性→启发式）
3. 求解（线性：pulp/scipy；GA：geatpy/手写30行）
4. 灵敏度（必做：约束右端±20%看最优值变化，算影子价格）

### 6.6 机理问题四步流程
1. 分析机理（找存量+流量，画存量-流量图）
2. 建立方程（微分：变化率=流入-流出；差分；元胞自动机：邻居+状态规则）
3. 求解（微分：odeint/solve_ivp；差分：递推；元胞：迭代）
4. 参数敏感性（有数据最小二乘拟合；无数据查文献取范围）

## 七、灵敏度分析要点

**为什么必做**：国赛评分硬性要求，缺了直接降档；评委必查。

**做什么**：
1. **参数扰动法**：把关键参数（权重、系数、约束右端值）分别上调/下调 ±10%（或±20%），重新求解，观察结果（排名/最优值/预测值）变化。
2. **影子价格**（优化题）：约束右端值+1单位，目标函数增量 = 影子价格，判断哪个约束是瓶颈。
3. **场景扫描**（机理/鲁棒题）：构造多组扰动场景（如环境温度65±5℃、导热率±5%，共12种组合），逐个重算。
4. **蒙特卡洛模拟**：参数按分布随机抽样N次（如1000次），看结果分布与波动范围。
5. **多模型对比**：换一个模型求解同一问题，对比结果一致性。

**怎么写进论文**：
- 表格对比扰动前后的关键指标（排名/最优解/预测值）。
- 结论措辞模板："当各指标权重发生±10%扰动时，前两名排名保持不变，模型具有良好鲁棒性。"
- 若结果对某参数敏感 → 诚实说明，并建议该参数需精确测定/增加安全裕度（如"最恶劣场景下建议额外增加0.5mm安全裕度"）。
