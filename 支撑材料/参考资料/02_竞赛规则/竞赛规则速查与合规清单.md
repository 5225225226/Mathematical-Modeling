# 全国大学生数学建模竞赛规则速查

> **来源**：`论文格式规范2026.pdf`（2026年修订稿）、`AI工具使用规定2026.pdf`（2026年试行）
> **用途**：备赛与论文撰写时的硬性合规清单，**违规可能取消评奖资格**。

---

## 一、论文格式规范（2026年修订稿）

### 1.1 纸质版格式

| 项目 | 硬性要求 |
|------|---------|
| 纸张 | 白色A4，单面/双面均可 |
| 页边距 | 上下左右各留至少 **2.5cm**，左侧装订 |
| 第1页 | **承诺书** |
| 第2页 | **编号专用页** |
| 第3页 | **摘要专用页**：含标题和关键词（无需英文翻译），原则上**不超过一页**；**从此页开始编页码**（页脚中部，阿拉伯数字从"1"起连续编号） |
| 第4页起 | **正文**：不要目录，**不超过30页** |
| 正文后 | **附录**（页数不限），必须打印并与正文装订在一起提交 |

### 1.2 附录硬性要求

- 内容应包括：**支撑材料文件列表** + 建模所用到的**全部完整、可运行的源程序代码**（含EXCEL、SPSS等软件交互命令）；
- **缺少必要源程序、程序不能运行或运行结果与论文不符，可能取消评奖资格**；
- 若确实没用到程序，须在附录中明确说明"本论文没有用到程序"。

### 1.3 匿名性

- 摘要专用页、正文、附录中**任何地方不得出现**参赛者身份、所在学校及赛区信息。

### 1.4 参考文献

- 所有引用他人或公开资料（含网上资料）的成果，必须按科技论文规范列出参考文献，并在正文引用处标注。

### 1.5 电子版格式

| 项目 | 硬性要求 |
|------|---------|
| 提交物 | 两个电子文件：参赛论文 + 支撑材料 |
| 论文格式 | 内容与纸质版完全一致；**单独一个文件**；PDF或Word（建议PDF）；**≤20MB** |
| 压缩 | **论文电子版不要压缩** |
| 首页 | 电子版第一页必须为**摘要专用页**（承诺书和编号专用页不放电子版中） |
| 支撑材料 | 至少含所有可运行源程序、自主查阅使用的数据资料、较大篇幅中间结果图表；用WinRAR压缩为一个文件（RAR/ZIP，**≤20MB**） |
| 支撑材料列表 | 须放入论文附录 |
| 例外 | 无支撑材料时在附录注明"本论文没有支撑材料" |
| 一致性 | 支撑材料与论文内容不相符，可能取消评奖资格 |
| 其他 | 承诺书、编号专用页不要放支撑材料中；所有文件不得含参赛者身份信息 |

### 1.6 其他

- 字号、字体、行距、颜色等不作统一要求；
- 本规范自发布之日起试行，旧规范与本规范不符的以本规范为准；
- 解释权归全国大学生数学建模竞赛组委会。

## 二、AI工具使用规定（2026年试行，2026年9月1日起）

### 2.1 基本原则

- 适用对象：大语言模型、生成式AI、代码辅助工具、AI智能体等；
- **不要求必须使用AI工具**；
- 使用AI须遵循**公开透明原则**，确保**核心建模与分析由参赛队主导**，对AI参与完成的内容**逐项人工审查与核实**。

### 2.2 AI工具使用声明（必设）

在论文**参考文献之前**设置"AI工具使用声明"，**二者择一**：

1. **未使用AI**："本参赛队在竞赛过程中未使用任何 AI 工具。"
2. **使用AI**："本参赛队在竞赛过程中使用了 AI 工具，主要用于【简要用途，如语言润色、代码调试等】，详细使用情况见支撑材料。"

### 2.3 AI工具使用详情.pdf（使用AI时必交）

使用AI的作品，支撑材料中须含 `AI工具使用详情.pdf`，内容包括：
1. 所用AI工具**名称、版本或型号**；
2. **具体使用目的和环节**；
3. **主要提示方式与使用过程说明**（可附典型交互示例）；
4. 对AI输出的**采纳、人工修改和核验的主要情况**（语言润色除外）。

### 2.4 违规后果

- 不符合规定 → 视为违反竞赛规则，按情节轻重处理；
- **故意隐瞒AI使用、作出虚假声明，或将未经必要人工审查与核实的AI生成内容直接作为核心建模与分析成果提交 → 取消评奖资格**。

## 三、备赛合规检查清单

论文提交前逐项核对：

- [ ] A4、页边距≥2.5cm、左侧装订
- [ ] P1承诺书、P2编号专用页、P3摘要页（≤1页）、P4起正文（≤30页、无目录）
- [ ] 摘要页起编页码（页脚中部，"1"起）
- [ ] 全文无参赛者/学校/赛区信息
- [ ] 参考文献规范、正文标注
- [ ] 附录：文件列表 + 全部可运行源码
- [ ] 电子版：单独文件、PDF/Word、≤20MB、不压缩、首页为摘要页
- [ ] 支撑材料：RAR/ZIP、≤20MB、与论文内容一致
- [ ] 参考文献前设置AI声明（二选一）
- [ ] 使用AI则支撑材料含 `AI工具使用详情.pdf`
- [ ] 核心建模由本队主导，AI内容已逐项人工审查核实
