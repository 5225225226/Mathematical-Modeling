## 一、论文概述

### 1.1 研究背景
- 能源危机与环境污染使各国大力发展新能源，锂电池凭借**无记忆效应、高能量密度、稳定的电化学性、循环寿命长、绿色环保**等优点成为主流储能元件。表1-1给出同一规格四类电池对比：

| 电池类型 | 额定电压值/V | 循环寿命/次 | 记忆效应 | 效率/% |
|---|---|---|---|---|
| 铅酸电池 | 2 | 400 | 无 | 85-90 |
| 镍镉电池 | 1.2 | 500 | 有 | 65-75 |
| 镍氢电池 | 1.2 | 700 | 有 | 50-65 |
| 18650锂电池 | 3.7 | 1000 | 无 | 95 |

- 锂电池随工作时间增加性能下降（主要表现是容量衰退），最终失效退役。市场预测：2020年全球锂电市场需求3166.62亿元、出货量200.38GWh；2025年达6942.65亿元、439.32GWh。
- 两大公开数据集来源：**NASA**（美国国家航空航天局，卓越故障预测研究中心）与 **CALCE**（马里兰大学先进寿命周期工程中心）。后续研究者多使用这两个数据集。

### 1.2 研究目标
- 从**数据驱动**角度，以**神经网络模型**为基础，对锂电池进行剩余寿命（RUL）预测；
- 将退役锂电池**梯次利用**到楼宇直流微网的混合储能系统中。

### 1.3 核心贡献（三大研究内容）
1. 采用 **LSTM 与 GRU** 神经网络设计时间序列预测模型，对比得出 **GRU 预测效果优于 LSTM**，并搭建 MATLAB GUI 实验仿真平台；
2. 提出 **EEMD + GRU（EEMD-GSGRU）组合模型**：EEMD 分解 → 各子序列 GRU 预测 → 网格搜索(GS)最优超参数 + Adam 优化，RMSE/MAPE 均显著优于 SVM、LSTM、GRU 单一模型；
3. 搭建**楼宇直流微网梯次利用平台**：当电池容量衰减到额定容量 80%~70% 时退役，经筛选后用于楼宇直流微网混合储能（退役锂电池 + 超级电容）。

## 二、核心知识点提炼

### 2.1 锂电池基本结构与工作原理
- **五大组成**：正极（活性物质+导电剂+黏结剂）、负极（碳材/石墨）、电解液（溶剂+锂盐，如六氟磷酸锂）、隔膜（聚烯烃多孔膜）、外壳（铝/钢/铝合金）。
- **分类**：按电解液（液态/固态）、外观形状（方形/圆柱/软包）、正极材料（三元/磷酸铁锂/锰酸锂/钴酸锂）、应用领域（消费/动力/储能）。
- **工作原理**：靠锂离子在正负极间往返的"**嵌入-脱离**"反应。充电时 Li+ 由正极跃迁至负极，放电时反向移动。反应式（M 为可替换金属材料）：
  - 正极：`LiMO₂ ⇌ Li₁₋ₓMO₂ + xLi⁺ + xe⁻`  (2-1)
  - 负极：`nC + xLi⁺ + xe⁻ ⇌ LiₓCₙ`  (2-2)
  - 总反应：`LiMO₂ + nC ⇌ Li₁₋ₓMO₂ + LiₓCₙ`  (2-3)

### 2.2 锂电池等效电路模型（对问题1机理建模有用）
| 模型 | 状态方程 | 特点 |
|---|---|---|
| 内阻模型 | `U_OC = U_L + I_L × R`  (2-4) | 最简单，开路电压源+内阻 |
| 戴维南(Thevenin)模型 | `U_OC = R₀×I_L + U_L + U_TH`  (2-5) | 加 RC 极化网络，表征极化 |
| PNGV 模型 | `U_OC = U_L + (1/C_b)∫I_L dt + R_pv·I_pv + R₀·I_L`  (2-6) | 戴维南串联电容 C_b，可经 HPPC 实验辨识 R_pv、R₀ |

### 2.3 锂电池性能参数（重点：容量）
- 容量单位 Ah 或 mAh，分**额定容量**（常温恒流恒压充满后再恒流放电至截止电压放出的电量，即最大可用容量）、**标称容量**（标准工况测定）、**剩余容量**、**理论容量**（与正极材料有关）、**实际容量**（实际工况放电总电量，表征性能状况）。
- 其它性能参数：内阻、电压、充/放电倍率、自放电率、充/放电效率、循环使用寿命、放电平台时间、电池组参数。
- **寿命表征**：容量衰退是寿命最直接指标；本文用"容量随时间（循环）序列"预测 RUL。

### 2.4 生命周期退化机理与关键现象
- 锂电池充放电本是可逆电化学反应，但内部会累积不可逆反应；过度充放电、频繁充放会削弱电荷储存能力，降到限值即生命周期结束。
- 衰退因素：电解液分解、隔膜老化、电极材料耗损、锂金属层形成等。
- **容量再生现象**：整体趋势下降，但局部出现"尖刺"回升——因充放电过程中产生电化学合成物，搁置后减少，依据可逆反应动态平衡，下一循环容量显示增大。
- 失效阈值定义：与初始容量相关，设定为 **1.4Ahr（初始容量 2Ah 的 70%）** 时判定失效退役。

### 2.5 NASA 数据集与测试流程（仿真数据构建的直接参考）
- 电池型号：**18650 钴酸锂离子电池，额定容量 2Ah**。
- 4 个电池（B5、B6、B7、B18）在室温下通过 3 种操作（充电、放电、阻抗）实验：
  1. 电压达 4.2V 前恒流 1.5A 充电；
  2. 充电电流降至 20mA 前恒压充电；
  3. 分别降至 2.7V(B5)、2.5V(B6)、2.2V(B7)、2.5V(B18) 前恒流 2A 放电；
  4. 0.1Hz~5kHz 扫频电化学阻抗谱扫描。
- 寿命结束标准：额定容量从 2Ah 降到 1.4Ah（降 30%）。
- **数据选取**：B5~B18 容量明显下降、数据量足；B45~B48 为加速老化、有效寿命过短，舍弃。最终选 **B5、B6、B7** 三组（B7 未退化到阈值但长度一致，保留作对照）。

### 2.6 文献综述中的方法谱系（问题2的"多模型对比"素材）
- **物理失效模型预测**：基于退化机理（SEI 膜生长模型、电极厚度变化）与经验退化模型（双指数经验模型、考虑库伦效率+粒子滤波）。局限：复杂环境不适用、需大量参数辨识。
- **数据驱动预测**：SVM（小样本非线性好，但需确定核函数/损失函数）、RVM（高稀疏性、计算量小，长期预测不准）、AR 自回归（训练时间长）、GPR 高斯过程回归（贝叶斯框架、非线性概率，参数多计算量大）、**神经网络（LSTM/GRU，最适合时序）**。
- 退役电池梯次利用：GE+ABB 风光储一体化、美国 EnerDel 公寓供电、德国博世/瓦腾福柏林 2MW/2MW·h 光伏储能电站、微电网群储能、主动配电网储能等案例。

## 三、关键技术方法

### 3.1 评价指标与归一化
- 归一化（[0,1]）：
  $$x_{norm} = \frac{x - \min}{\max - \min} \tag{4-10}$$
- 平均绝对百分比误差 MAPE：
  $$MAPE = \frac{1}{m}\sum_{i=1}^{m}\frac{|x_i - \hat{x}_i|}{x_i} \times 100\% \tag{4-11}$$
- 均方根误差 RMSE：
  $$RMSE = \sqrt{\frac{1}{m}\sum_{i=1}^{m}\left(\frac{x_i - \hat{x}_i}{x_i}\right)^2} \times 100\% \tag{4-12}$$
- RUL 绝对误差：`RUL_error = RUL_true − RUL_prediction`  (3-9)

### 3.2 LSTM 网络
- LSTM 为 RNN 改进型，解决 RNN 长距离依赖与梯度消失问题，由**遗忘门、输入门、输出门**组成（图3-1~3-5）。设 x_t 为输入，y_t 为输出，y_{t-1} 为上时刻输出，C_t、C_{t-1} 为当前/上时刻记忆单元状态，C'_t 为候选记忆：
  - 遗忘门：$f_t = \sigma(W_f^T y_{t-1} + U_f^T x_t + b_f)$  (3-1)
  - 输入门：$i_t = \sigma(W_i^T y_{t-1} + U_i^T x_t + b_i)$  (3-2)
  - 候选记忆：$C'_t = \tanh(W_c^T y_{t-1} + U_c^T x_t + b_c)$  (3-3)
  - 输出门：$O_t = \sigma(W_o^T y_{t-1} + U_o^T x_t + b_o)$  (3-4)
- 预测结构：LSTM 层 + 全连接层，输入滑动窗口的容量序列，输出未来容量（图3-6）。

### 3.3 GRU 网络
- GRU 为 LSTM 变体/改进型，将**遗忘门与输入门合二为一**为更新门，结构更简、训练更快。由**更新门 z_t 和重置门 r_t** 组成：
  - 更新门：$z_t = \sigma(W_z [y_{t-1}, x_t])$  (3-5)
  - 重置门：$r_t = \sigma(W_r [y_{t-1}, x_t])$  (3-6)
  - 候选输出：$\tilde{y}_t = \tanh(W \cdot [r_t \cdot y_{t-1}, x_t])$  (3-7)
  - 最终输出：$h_t = (1 - z_t) * y_{t-1} + z_t * \tilde{y}_t$  (3-8)

### 3.4 EMD 经验模态分解
- Huang(1998) 提出，时域滤波算法，将信号分解为若干**本征模态函数 IMF**（按频率从高到低）与余项。
- 分解步骤：① 由局部极大/极小值点构造上下包络线 U(t)、L(t)；② 求均值 $f_1(t) = (U(t)+L(t))/2$ (4-1)；③ 作差 $h_1(t) = x(t) - f_1(t)$ (4-2)；④ 判断 h₁ 是否满足 IMF 特征条件，否则重复①②③；⑤ 分离出 c₁(t) 后对余项 $r_1(t) = x(t) - c_1(t)$ 继续分解，最终 $x(t) = \sum_{t=1}^{m} c_1(t) + r(t)$ (4-3)。
- **缺陷**：模态混叠——某 IMF 中混入差异大的时间尺度特征（B5/B6/B7 用 EMD 分解时 IMF1、IMF2 明显混叠）。

### 3.5 EEMD 集合经验模态分解
- Wu 等提出，在 EMD 基础上加入**白噪声辅助**以改善模态混叠。原理：白噪声频谱能将不同时间尺度信号自动分布到标准参考尺度上，多次平均后噪声归零，结果用集成均值表示。
- 步骤：
  - Step1：将均值 0、幅值 σ 的高斯白噪声加入原始信号：$x_i(t) = x(t) + n_i(t)$  (4-4)
  - Step2：对每个 x_i(t) 做 EMD 分解，得 IMF $c_{ij}(t)$（第 i 次加噪后第 j 个 IMF）与余项 r_i(t)；
  - Step3：集成平均：$c_j(t) = \frac{1}{M}\sum_{i=1}^{M} c_{ij}(t)$  (4-5)
- 分解结果：B5/B6/B7 各分解为 **IMF1~IMF5 + 残差（共6部分）**。其中 **IMF1~IMF3 无规律、占比小、波动强 → 随机因子**；**IMF4、IMF5 及残差平滑、占比大 → 趋势因子**。趋势因子预测影响远大于随机因子，随机因子的拟合/泛化程度决定"最后一公里"精度。

### 3.6 EEMD-GSGRU 组合模型（算法流程，表4-1）
```
1: 输入：电池容量数据 Data，算法参数；
2: 输出：组合模型；
/* 数据预处理 */
3: 使用 0-1 归一化消除数据量纲影响；
4: 利用 EEMD 分解数据获得 N 条子数据；
5: 根据子数据集建立 N 个子 GRU 模型；
6: 子模型输出与原数据集相加；
/* GRU 实时预测模型 */
7: 使用 80 个时刻数据前向计算每个神经元权重；
8: 反向计算每个神经元的误差项；
9: 使用优化策略减小网络误差，更新网络权重参数；
10: 前三时刻数据输入，第 4 时刻数据输出；
11: 数据前 80 时刻作为模型训练集，预测第 81 时刻值；
12: 将预测值回填原数列，模型滑窗 1 个时刻，迭代预测 80 个时刻；
/* 参数优化 */
13: 使用 GS 搜索模型最优参数；
/* 集成 */
14: 子模型同索引值相加；
15: 进行电池寿命预测。
```
- **实时滚动预测机制**：一次训练 80 个点只预测第 81 时刻，预测值回填后滑窗 1 步，再预测下一个时刻，如此迭代完成 80 个目标时刻的预测。**每次循环运行 10 次取平均值**作为最终预测值。
- **滞后相关性依据**：B5/B6/B7 容量在 t 与 t+1/t+2/t+3 时刻间有较强滞后正相关（图4-9），故用**前三时刻值预测第四时刻值**（输入维度 3，输出维度 1）。

### 3.7 网格搜索（GS）超参数寻优
- GS 通过穷举遍历给定参数组合自动调参，选取 GRU 的**迭代次数与隐藏层神经元数**两个整数参数。
- 寻优空间：迭代次数 50~500 轮、步长 50；隐藏层神经元数 5~50 层、步长 5。**寻优空间共 100 组**，用 B5 数据寻优。
- 最优参数（表4-2）：

| 参数 | 隐藏神经元数 | 输入维度 | 输出维度 | 学习率 | 批次大小 | 时间步长 | 迭代次数 | 优化策略 |
|---|---|---|---|---|---|---|---|---|
| 最优值 | 15 | 3 | 1 | 0.0006 | 20 | 1 | 300 | Adam |

- 调参结论（图4-10、4-11）：迭代 50 代 MAPE 值域广（约2~6）不稳定；**300 代 MAPE 中位数最小、值域最稳定（MAPE 均<1）**，每次迭代约需 500 秒；400 代箱型虽最小但有离群值且耗时更长。隐藏层 5 层误差箱最长最不稳；**15 层最稳定精确**；>15 层无明显优势且偶有离群、有过拟合趋势，但 15 层完成 80 时刻预测约需 600 秒。

### 3.8 Adam 优化
- 自适应矩估计（Adaptive Moment Estimation）优化策略用于更新 GRU 网络权重参数，结合动量与自适应学习率。

## 四、实验与结论

### 4.1 第三章实验：LSTM vs GRU
- 预测起点分别设为 **60、80、100 Cycle**，用历史容量训练后预测未来 100、80、60 个循环周期。真实寿命终点：B5 = 124 Cycle，B6 = 109 Cycle（B7 未到阈值作对照）。
- RUL 绝对误差对比：

| 电池 | 模型 | 起点60 误差 | 起点80 误差 | 起点100 误差 |
|---|---|---|---|---|
| B5 | LSTM | 4 | 4 | 4 |
| B5 | GRU | 2 | 1 | 1 |
| B6 | LSTM | 5 | 4 | 2 |
| B6 | GRU | 1 | 1 | 1 |

- 容量预测偏差基本在 **0.2 范围内**波动，GRU 误差波动更小。**结论：LSTM 与 GRU 均有效，GRU 效果更好**（结构更简、训练更快）。

### 4.2 第四章实验：EEMD-GSGRU
- 训练设置：真实值与测试值共 160 点，前 84 点训练、后 76 点验证（测试），滚动预测后 80 时刻。
- 表4-3 EEMD-GSGRU 预测 B5~B7 的 80 时刻误差：

| 数据集 | 误差类别 | 平均值 | 最大值 | 最小值 |
|---|---|---|---|---|
| B5 | RMSE | 0.0169 | 0.0417 | 0.0001 |
| B5 | MAPE | 1.1921 | 2.9296 | 0.0080 |
| B6 | RMSE | 0.0309 | 0.1307 | 0.0003 |
| B6 | MAPE | 2.2706 | 8.9347 | 0.0216 |
| B7 | RMSE | 0.0111 | 0.0362 | 0.0007 |
| B7 | MAPE | 0.7279 | 2.1899 | 0.0467 |

- **表4-4 RMSE 对比**（80 个预测值平均值）：

| 数据集 | SVM | LSTM | GRU | EEMD-GSGRU |
|---|---|---|---|---|
| B5 | 0.0806 | 0.0511 | 0.0510 | **0.0169** |
| B6 | 0.0804 | 0.0866 | 0.0817 | **0.0309** |
| B7 | 0.0679 | 0.0475 | 0.0428 | **0.0111** |

- **表4-5 MAPE 对比**：

| 数据集 | SVM | LSTM | GRU | EEMD-GSGRU |
|---|---|---|---|---|
| B5 | 5.6790 | 3.7087 | 3.7014 | **1.1921** |
| B6 | 6.0625 | 6.5081 | 6.1657 | **2.2706** |

- **结论**：EEMD-GSGRU 在精确性与稳定性上均高于 SVM、LSTM、GRU 单一模型；B5、B7 拟合最好，B6 有部分离群值（可能因滞后相关性图中离群点）。最优拟合点 RMSE 分别达 0.0001、0.0003、0.0111；MAPE 达 0.0080、0.0216、0.0467。

### 4.3 第五章实验：楼宇直流微网梯次利用仿真
- 系统结构：光伏（P_G）+ 直流负荷（P_L）+ 混合储能（退役锂电池 P_BAT + 超级电容 P_SC），通过双向 DC/DC 变换器（Buck/Boost，互补 PWM 驱动）接直流母线。
- 混合储能承担功率：$P_H = P_G - P_L = P_{BAT} + P_{SC}$  (5-3)。P_H>0 充电（光伏过剩），P_H<0 放电（负荷高于光伏）。
- 控制策略：**低通滤波器分频**——高频功率给超级电容（功率密度大、响应快），低频功率给退役锂电池（能量密度大、动态响应差）；功率-电压外环 + 电流内环双闭环 PI 控制（外环 $i_{ref} = (k_{pi} + k_{il}/s)(P_{ref}/U)$，内环 $U = (k_{pi} + k_{in}/s)(i_{ref}-i)$，k_pi=1.5，k_il=k_in=1）。
- 仿真结果：给定参考总功率 1250W（10 个时刻正负交替）；超级电容约 **0.025s** 响应到约 1200W，**0.06373s** 达峰值 1236W（与给定差 14W，由退役锂电池补足）；锂电池初始 SOC 70%、超级电容初始 SOC 100%；大负荷实验 0~6s 锂电池 SOC 从 70% 降到约 30%。
- **结论**：混合储能能很好平抑楼宇直流微网功率波动，超级电容迅速响应，退役锂电池提供主体功率。

### 4.4 退役阈值与梯次利用评估
- **退役判定**：当动力电池（本文以电动汽车磷酸铁锂电池为对象）容量衰减到**额定容量的 80%~70% 以下**即不满足动力需求，退役回收；性能满足储能系统需求，可降低储能装备成本。
- **梯次利用前评估项**：① 外观检测（鼓胀、电极损坏）；② 电压、内阻检测；③ 容量检测（如 RT9428 检测装置）。目前退役电池检测筛选无成熟标准，本文在理想条件下（筛选合格、完全满足梯次利用要求）进行仿真。

## 五、对A题建模的启示

### 问题1（退化特征分析与影响因子辨识）
- **退化曲线形态**：用本文"容量初期缓慢衰减 → 指数型衰退 + 局部容量再生尖刺"描述退化规律；退化过程贯穿全生命周期，是连续时序过程。
- **阶段划分**：以失效阈值（额定容量 70%，即 2Ah→1.4Ah）为失效临界；可进一步用分段线性回归/拐点检测划分"正常运行→性能劣化→失效临界"三阶段。
- **影响因子机理**：直接引用本文退化机理（电解液分解、隔膜老化、电极材料耗损、锂金属层形成）+ 等效电路模型（内阻/戴维南/PNGV）描述内阻、极化变化；再补充温度（Arrhenius）、充放电倍率、DOD、充电方式等。
- **因子量化**：相关性分析（Pearson/Spearman/Kendall）、随机森林特征重要性、灰色关联度、熵权法——注意本文未做定量权重，需自补。
- **坑**：容量再生现象会让简单拟合失真，量化因子时不要忽视局部回升。

### 问题2（SOH评估与RUL预测）
- **SOH 定义**：SOH = 当前最大可用容量 / 额定容量，用容量序列作为寿命指示（本文核心思想）。
- **模型主线**：先做基线 LSTM → GRU → 组合模型 EEMD+GRU（可仿本文加 GS 网格搜索 + Adam）。这是"多模型对比 + 组合创新"的最稳路线。
- **RUL 输出方式**：定义预测起点（如 60/80/100 Cycle），用 RUL 绝对误差（3-9）汇报；用**滚动预测**（训练 80 点预测 81 点→回填→滑窗1）保证实时性，多次运行取平均。
- **评价指标**：必须同时给 **RMSE、MAPE**（本文标准做法），并汇报最大/最小/平均值，增强说服力。
- **不确定性**：本文未做置信区间，可补蒙特卡洛/贝叶斯/多模型多次运行标准差，提升深度。
- **极端工况**：用自建仿真数据加高低温、过充过放、大倍率扰动做鲁棒性验证（呼应问题4）。
- **坑**：① NASA 原始数据只有几十个循环点、序列短，直接训练深度学习易过拟合——用 EEMD 分解降低序列复杂度、小网络（隐藏层 15）是本文应对思路；② 训练时间长（300 代约 500s/次），比赛注意控制算力；③ 归一化后 RMSE/MAPE 才可比。

### 问题3（退役筛选与储能编组多目标优化）
- **退役阈值**：直接采用 **80%~70% 额定容量**作为筛选门槛（本文第4、5章依据）；配合电压、内阻、SOH、RUL 多维指标。
- **筛选编组方法**：借鉴 Fast Clustering 论文（见另一份精读）的**两步学习法**：Step1 按品牌/型号/批次/历史信息分大类，Step2 用脉冲/容量特征做 K-means 或 GMM 聚类。本文的"同制造商、同型号、同批次、同性能"约束可作编组一致性约束。
- **编组优化**：在聚类分组基础上做多目标优化（NSGA-II 求帕累托前沿 + TOPSIS 选折中），决策变量用 0-1 整数规划表达电池-编组配对关系；约束用一致性阈值（容量/内阻差异）、安全阈值、编组数量、成本。
- **坑**：聚类前务必处理异常电池（Fast Clustering 的 Cluster 12 有异常电池）；OCV/容量范围差异大的电池不宜同组。

### 问题4（多工况仿真、鲁棒性与工程建议）
- **场景仿真**：按本文楼宇直流微网框架设置工况扰动（温度、倍率、批次离散度），重跑"预测+筛选编组"全流程。
- **灵敏度分析**：关键参数 ±10%、±20% 梯度扰动，观察 RMSE/MAPE、编组方案、SOC 曲线变化——本文对迭代次数/隐藏层数的箱型图分析（4.4.3）就是灵敏度分析的雏形，可直接模仿成箱型图/误差带。
- **鲁棒性**：多场景结果对比 + 置信区间 + 风险矩阵。
- **工程建议**：结合结果给出量化建议——退役阈值（80%/70% 还是更低）、筛选标准、编组规模、运维策略（如本文提到的全生命周期健康管理、超级电容+退役锂电池混合储能配置）。
- **坑**：楼宇微网部分本文是理想条件仿真（光伏用电压源+电阻代替），比赛若要复现需说明简化假设的合理性。

## 六、可复用的代码/数据思路

> A题**不提供原始数据**，需自建仿真数据。本文提供的数据/机理/参数可作为仿真数据生成依据。

1. **退化曲线生成**：按本文形态生成容量随时间序列——指数/双指数衰减 + 噪声 + 局部容量再生尖刺。可参考经验退化模型：`Q(t) = a·exp(-b·t) + c·exp(-d·t) + e`，再加高斯噪声与周期性再生扰动。
2. **用开源数据集校准**：可直接下载 **NASA PCoE Battery Data Set**（B5/B6/B7/B18，2Ah 18650 钴酸锂，本文所用）作为仿真曲线校准基准；若需更多电池，参考 MIT/Stanford 电池大数据集。
3. **多因素注入**：温度用 Arrhenius 加速因子、倍率/DOD/充电方式按文献规律调节衰减速率 b；批次差异按正态分布生成初始容量/内阻（用于问题3筛选编组）。
4. **预测模型代码骨架**：
   - 数据预处理：0-1 归一化（4-10）；
   - EEMD 分解：`PyEMD` 库（EEMD 类，设置白噪声幅值、集成次数 M）；
   - GRU 建模：Keras/PyTorch，输入维度 3、输出维度 1、隐藏层 15、学习率 0.0006、batch 20、epoch 300、Adam；
   - 滚动预测：训练 80 点→预测第 81 点→回填→滑窗 1，迭代 80 次；循环 10 次取平均；
   - 超参搜索：`GridSearchCV` 思路手写（迭代 50~500/步长50，隐藏层 5~50/步长5）。
5. **评价函数**：按 (4-11)(4-12) 实现 MAPE、RMSE；RUL 误差按 (3-9)。
6. **聚类筛选代码**：K-means 用 `sklearn.cluster.KMeans`，GMM 用 `sklearn.mixture.GaussianMixture`（伪代码见 Fast Clustering 精读）；聚类特征取 OCV、测试容量、脉冲响应特征；聚类后按簇内一致性校验（容量/内阻差异阈值）。
7. **楼宇微网仿真**：Simulink 或 Python（如用 `matplotlib` 画 SOC/功率曲线）复现功率平衡 P_H = P_G - P_L、低通滤波分频 + 双闭环 PI 控制；关键参数：参考功率 1250W、锂电池 SOC 初值 70%、超级电容 100%。
