# 数学建模数据获取指南

> **来源**：`数学建模如何快速获取数据.docx`（数学建模钉子户，2021）精炼整理 + A题仿真数据构建补充
> **核心痛点**：建模没数据。国赛一般给的数据很少，甚至不给数据（如本次A题要求自主构建仿真数据）。

---

## 一、常用数据获取渠道

### 1. Kaggle
- **定位**：机器学习竞赛、托管数据库、代码分享平台，大量公开免费数据。
- **链接**：https://www.kaggle.com
- ✅ 优点：数据准确，真实性有保障。
- ❌ 缺点：谷歌旗下，国内数据源少；有时下载速度感人；需注册账号（验证码可能出不来——**建模开始前先踩坑**）。

### 2. 国家数据（国家统计局）
- **定位**：历年国家工业、农业、科技等行业数据的官方窗口。
- **链接**：https://data.stats.gov.cn
- ✅ 优点：数据准确、真实；自带可视化模块。
- ❌ 缺点：数据颗粒比较大，没有细化的微观数据。

### 3. GitHub - Awesome Public Datasets
- **定位**：维护全球40+国家涵盖科技、文化、农业、天气、经济等领域的数据集链接（仅提供数据源链接）。
- ✅ 优点：领域覆盖广。
- ❌ 缺点：数据源真实性不能保证；外网下载速度感人。

### 4. 和鲸（中国版Kaggle）
- **定位**：中国版的Kaggle，数据集较多、覆盖范围广。
- ✅ 优点：下载速度快，数据真实性有保证。
- ❌ 缺点：数据集数量不如上面几个多。

## 二、A题仿真数据构建指南（核心补充）

本次校内赛A题（锂电池剩余寿命预测）**不提供原始实测数据**，需自主构建仿真时序数据与参数体系。以下思路结合资料文件夹中的两篇A题论文：

### 2.1 构建原则
1. **有机理依据**：退化规律须符合锂电池老化机理（容量衰减、内阻升高）；
2. **有参数体系**：容量、内阻、温度、倍率、循环次数、DOD等参数须成体系；
3. **有文献支撑**：取值可参考真实电池数据集（NASA、MIT/Stanford）或论文参数；
4. **有随机性**：加入噪声与批次差异，体现非线性、随机性、时变性。

### 2.2 建议的退化模型形态
- **经验退化模型**：容量随循环次数的指数/双指数衰减，后期加速下降：
  `Q(n) = Q0 · (a·exp(b·n) + c·exp(d·n)) + ε`
- **温度加速**：Arrhenius方程 `k = A·exp(-Ea/(R·T))`，高温加速老化；
- **倍率/DOD影响**：大倍率、深放电加速退化（可用乘数因子）；
- **阶段特征**：正常运行（缓慢线性）→ 性能劣化（加速）→ 失效临界（剧烈衰减），可构造分段函数。

### 2.3 影响因素注入
- 循环次数：主时间轴；
- 环境温度：不同温度下退化速率不同；
- 充放电倍率：C-rate 对老化速率影响；
- 放电深度（DOD）：深放电更伤电池；
- 充电策略：过充、快充加速老化。

### 2.4 批次差异（问题3需要）
- 同一型号电池初始容量/内阻呈正态分布；
- 用K-means/GMM聚类可自然分出批次等级 → 支撑筛选编组。

## 三、数据预处理通用要点

拿到数据后（无论真实还是仿真）：
1. 缺失值填充（均值/中位数/插值/前向填充）；
2. 异常值检测（IQR / 3σ法则）；
3. 平稳化（差分/对数变换，时序预测前）；
4. 标准化/归一化（MinMax / Z-score，机器学习前）；
5. 特征工程（滞后特征、滑窗统计、时序分解）。
