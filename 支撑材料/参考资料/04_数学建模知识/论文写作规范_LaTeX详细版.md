> **适用场景**：全国大学生数学建模竞赛（CUMCM）论文撰写，严格按组委会最新格式规范，并结合优秀论文的学术逻辑、图表丰富度、论证深度要求生成高质量 LaTeX 论文。

> **整理时间**：2026-08

## 一、基础格式规范（强制遵循）

### 1.1 页面与版心

- 纸张：**A4**，单面或双面打印均可。
- 页边距：上下左右均 **不少于 2.5 cm**，建议统一设为 2.5 cm。
- 装订：左侧装订，无特殊装订线要求。

### 1.2 页码与页面结构

- **承诺书**（第一页）和**编号专用页**（第二页）：不编页码，且**不出现在电子版论文中**。
- **摘要专用页**（第三页）为论文第 1 页：页码从该页开始，位置**页脚居中**，阿拉伯数字连续编号。
- 正文从第四页开始，**无目录**。
- 正文总页数 **不超过 30 页**，附录页数不限，附录随正文后装订。

### 1.3 摘要专用页

- 单独一页，内容包含：论文标题、摘要、关键词。
- **无需英文翻译**。
- 摘要字数建议 **200～300 字**，概述问题、方法、模型、结果、结论。
- 关键词 **3～6 个**，用分号分隔。
- 该页不能有任何显示参赛者身份、学校、赛区的信息。

### 1.4 正文与附录

- 正文从第四页开始，按「一、问题重述」「二、模型假设」「三、符号说明」等依次排列，结构自行设计。
- 正文后紧跟**参考文献**，再后为**附录**。
- 附录至少包含：
  - 支撑材料文件列表（说明压缩包内容）；
  - 建模所用到的**完整、可运行的源程序代码**（Python/MATLAB/SPSS 等），并附关键注释；
  - 若确无程序，需在附录中声明「本论文没有用到程序」。
- 摘要、正文、附录中任何位置都不得出现参赛者个人信息、学校名称或赛区。

### 1.5 字体、字号与行距（建议标准）

国赛未做硬性规定，但为保证评阅美观，建议采用通用学术格式：

| 内容 | 字体 | 字号 | 行距/其他 |
|------|------|------|-----------|
| 正文 | 宋体 | 小四（12pt） | 1.5 倍行距，首行缩进 2 字符 |
| 一级标题 | 黑体 | 小三（15pt）或小二号 | 居中或左对齐，段前段后留间距 |
| 二级标题 | 黑体 | 四号（14pt） | 左对齐 |
| 三级标题 | 宋体加粗 | 小四 | 左对齐 |
| 代码 | 等宽字体（Courier New / Consolas） | 小五（9pt） | 行距 1.0 |
| 表格内容 | 宋体 | 五号或小五号 | 紧凑行距 |

### 1.6 参考文献与引用

- 凡引用他人成果（含网络资料），**必须按科技论文规范列出参考文献**，并在正文引用处标注序号（如 [1]）。
- 参考文献格式推荐 **GB/T 7714-2015**。
- 文献数量 **≥10 篇**，涵盖专著、期刊、学位论文、电子文献等。

## 二、写作逻辑与论证深度要求

### 2.1 段落逻辑链（强制每段遵循）

```
目的陈述 → 方法选择（含理由） → 具体操作（含参数设置） → 结果呈现（含数据） → 验证与解释
```

**示例**：

> 为准确识别起跳时刻，考虑到脚部关键点在离地瞬间存在纵向位移的急剧变化，本文选取脚部关键点 29～32 的纵坐标均值作为判别指标。为避免噪声干扰，首先对数据进行 Savitzky‑Golay 平滑（窗口宽度 7，三阶多项式），随后采用一阶微分法计算速度序列。经多次实验，将速度阈值设为 150 px/s 以区分正常摆动与起跳。最终检测到运动者 1 的起跳时刻为 4.133 s（帧号 124），落地时刻为 4.567 s（帧号 137），滞空时间 0.434 s。通过与实测成绩反算的比例尺（0.334 cm/px）对比，两名运动者比例尺一致，验证了该识别方法的可靠性。

### 2.2 数据呈现原则

- 不得孤立罗列数字，每个数据后必须紧跟解释。
- 精确度合理：时间保留至 0.001 s，角度至整数度，比例尺至 0.001 cm/px。
- 所有对比需明确基准和变化幅度（提升率、误差率等）。
- 异常值必须讨论原因，不能简单剔除。

### 2.3 论证三层次（现象‑归因‑推论）

| 层次 | 内容 |
|------|------|
| 现象层 | 描述图表或计算出的具体数值、趋势 |
| 归因层 | 从运动生物力学、物理学机理或数学性质解释成因 |
| 推论层 | 点明该发现对后续建模的意义或在实际教学中的应用价值 |

## 三、图表规范（提升丰富度与专业度）

### 3.1 表格

- 数量要求：全文表格建议 **12～18 个**，每个核心步骤至少一个表格。
- 格式：**三线表**（`\toprule, \midrule, \bottomrule`），表号及标题置于表格上方（如「表 1 起跳与落地时刻识别结果」）。
- 内容：必须包含数据对比、参数选择、误差分析等，且在表格下方用一段文字解读。

### 3.2 图片

- 数量要求：全文图片建议 **18～25 张**，关键分析必配图。
- 格式：矢量图优先（PDF 格式），分辨率不低于 **300 dpi**；图号及标题置于图片下方。
- 内容：数据前后对比图、关键点轨迹图、角度变化曲线、热力图、散点图、雷达图等。
- 代码生成图片：所用绘图源程序应附在附录中。

### 3.3 图表引用

- 正文中必须先见「如图 X 所示」「见表 Y」再出现图表，图表紧随对应段落之后。

### 3.4 图片生成/识别工具（Ollama 视觉模型）

> 当需要完成图片相关的工作（识别图片内容、OCR 提取图表数据、对截图/照片做分析描述、或将图表转换后接入正文分析）时，**可直接调用本机 Ollama 的可用图片模型**。

本机已安装的视觉模型：

| 模型 | 用途 | 大小 |
|------|------|------|
| `minicpm-v:latest` | 图片理解 / OCR / 图表数据提取 / 截图分析 | 5.5 GB |

**命令行用法**（识别图片内容）：

```bash
# 方式一：交互式（会在结果前询问 "What's in this image?"）
ollama run minicpm-v "D:/path/to/图片.png"

# 方式二：一次性查询，直接附上图片路径
ollama run minicpm-v "请识别这张图并输出表格中的数据" /path/to/图片.png

# 方式三：API 调用（默认端口 11434）
curl http://localhost:11434/api/generate -d '{
  "model": "minicpm-v",
  "prompt": "描述这张图的内容并提取关键数据",
  "images": ["<base64编码的图片>"],
  "stream": false
}'
```

**注意事项**：
- 若识别结果不理想，可先对图片做预处理（放大、转灰度、增强对比度）再调用。
- 用于论文配图的**生成/绘制**仍建议用 matplotlib/Python 生成矢量图（PDF），模型识别的数据可作为图表内容依据。
- 可用 `ollama list` 查看当前全部可用模型；如需新增图片模型可 `ollama pull <模型名>`。
- 其他本地视觉能力见 `local-vision-model` 技能与 `image-ocr-processing` 技能。

## 四、论文结构与页码分配建议

根据国赛规范，正文主体结构可安排如下（页数参考）：

| 章节 | 建议页数 | 核心内容 |
|------|---------|----------|
| 摘要 | 1 页 | 问题、方法、模型、结果、结论、关键词 |
| 一、问题重述 | 1‑2 页 | 背景、问题梳理、文章结构 |
| 二、模型假设与符号说明 | 1‑2 页 | 假设清单（附依据）、符号一览表 |
| 三、数据预处理 | 2‑3 页 | 异常值、坐标转换、平滑滤波、帧率统一 |
| 四、问题一 | 4‑6 页 | 方法设计、微分识别、比例尺验证、轨迹拟合、角度计算 |
| 五、问题二 | 5‑7 页 | 体质因素相关性、姿态调整效果、角度与成绩相关、成人‑儿童对比 |
| 六、问题三 | 4‑5 页 | 特征构建、随机森林回归、多元线性回归、模型对比与误差分析 |
| 七、问题四 | 3‑5 页 | 问题诊断、参照选取、角度对比、改进方案、成绩预测 |
| 八、结论与展望 | 1‑2 页 | 全文总结、创新点、不足与改进 |
| 参考文献 | 1 页 | 不少于 10 篇 |
| 附录 | 若干页 | 源程序、支撑材料清单、额外图表 |

> ⚠️ 正文总页数不超过 30 页，附录可超 30 页。

## 五、附录与支撑材料规范

### 5.1 附录内容

- **支撑材料文件列表**：列出压缩包中所有文件及其用途。
- **源程序代码**：完整代码，按问题或模型分块，添加关键注释，行号可选。
- **额外结果图表**：正文不便放置的大表格、中间计算结果等。

### 5.2 支撑材料电子文件

- 将所有源程序、数据、中间结果等打包为 `.zip` 或 `.rar`，大小 **≤20 MB**。
- 压缩包内文件名清晰，**禁止出现参赛者信息**。
- 电子版论文本身为 PDF 或 Word（建议 PDF），大小 **≤20 MB**，不加承诺书和编号页，第一页为摘要页。

## 六、LaTeX 模板建议

推荐使用 `ctexart` 文档类，核心导言区示意：

```latex
\documentclass[12pt,a4paper]{ctexart}
\usepackage[top=2.5cm,bottom=2.5cm,left=2.5cm,right=2.5cm]{geometry}
\usepackage{amsmath,amssymb}
\usepackage{graphicx,subfig}
\usepackage{booktabs,multirow,longtable}
\usepackage{caption}
\usepackage{fancyhdr}
\usepackage{hyperref}
\usepackage{cite}
\usepackage{float}
\usepackage{xcolor}
\usepackage{enumitem}
\usepackage{titlesec}
% 页码设置：摘要页开始编号，页脚居中
\pagestyle{fancy}
\fancyhf{}
\fancyfoot[C]{\thepage}
\renewcommand{\headrulewidth}{0pt}
\titleformat{\section}{\centering\heiti\sanhao}{}{0em}{}
\titleformat{\subsection}{\heiti\sihao}{}{0em}{}
\titleformat{\subsubsection}{\heiti\xiaosi}{}{0em}{}
\setlength{\parindent}{2em}
\linespread{1.5}
```

> ⚠️ 所有模板代码必须自行检查，确保无个人信息泄露（如 PDF 元数据中的作者字段）。

## 七、生成论文的 AI 提示词（可直接使用）

```
请根据 2026 年全国大学生数学建模竞赛论文格式规范，为我生成一篇完整的 LaTeX 论文源文件。
【题目】学生立定跳远过程的 AI 量化分析与成绩预测
【关键词】立定跳远；数值微分；Spearman 相关；多元线性回归；姿势优化
【格式要求】
- 使用 ctexart 文档类，A4 纸，页边距 2.5 cm，12pt，1.5 倍行距。
- 第一页为摘要专用页（含标题、摘要、关键词），不插入页码，后续正文从第 4 页开始编页码，页脚居中。
- 不要目录，不要承诺书和编号页。
- 正文后附参考文献（GB/T 7714 格式，≥10 篇），再后为附录（包含程序代码和支撑材料清单）。
- 全文无任何参赛者信息。
【写作风格】
- 每段按"目的→方法（含理由）→操作（参数）→结果（数据）→验证/解释"的逻辑链撰写。
- 使用"首先…其次…随后…最后…进一步地…据此…"等衔接词保持条理。
- 每个结论包含现象描述、物理/生物力学归因、建模意义三层递进。
- 避免口语化，杜绝空泛套话，所有数据必须有解读。
【内容与篇幅】
- 问题重述（1.5 页）、数据预处理（3 页）、问题一：起跳落地识别与运动描述（5 页）、问题二：关键因素分析（6 页，含体质和姿态）、问题三：成绩预测模型（4 页，对比两种模型）、问题四：个体诊断与训练建议（3 页）、结论与展望（1 页）。
- 全文表格 14～16 个，图片 20～22 张，每个图表前后均有文字分析。
- 附录提供核心 MATLAB/Python 代码，支撑材料清单。
请直接生成完整的 `.tex` 文件，从 `\documentclass` 开始到 `\end{document}` 结束。
```

## 八、注意事项与常见违规点

| 状态 | 违规点 | 后果 |
|------|--------|------|
| ❌ | 摘要页超过一页 | 扣分 |
| ❌ | 正文出现目录 | 不合规 |
| ❌ | 电子版论文包含承诺书或编号页 | 直接取消资格 |
| ❌ | 任何位置出现校名、姓名、赛区 | 违纪 |
| ❌ | 附录无程序或程序不能运行 | 可能被降等 |
| ❌ | 支撑材料与论文内容不符 | 可能取消资格 |
| ✅ | 所有引用均标序号，并在参考文献列表中完整给出 | — |

按此规范写作，既可满足国赛严格的格式审查，又能产出逻辑严密、图表丰富、篇幅饱满的高质量论文。
