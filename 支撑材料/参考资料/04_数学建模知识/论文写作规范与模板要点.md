# 论文写作规范与模板要点

> 资料来源：2026国赛零基础获奖速成课讲义第8-10章、全流程速成课讲义第6部分、2026数模国赛word国奖级模板、2026数学建模国赛标准论文Word模板、2026年国赛AI工具使用详情模板、2025国赛创新型算法汇总。本文件为备赛AI的论文写作规范知识。

## 一、论文的核心地位与评阅标准

**论文是三天工作的最终成果物，是评定成绩好坏、获奖级别高低的唯一依据。**

评阅主要依据四个方面：
1. **假设的合理性**
2. **建模的创造性**（不是方法越高深越有创造性；可体现在论文各个环节；基于对方法的掌握和对问题的透彻理解）
3. **结果的正确性**
4. **文字表达的清晰程度**

**误区警示**：
- 误区一：模型建好就行，论文是次要的 —— 错误，建模是基础，论文是表达，两者相辅相成。
- 误区二：论文写得华丽就行，模型能用即可 —— 错误，模型是核心。
- 论文不是个人的事，需全队配合；写作要在第三天基本完成；摘要至少留出4-6小时。

## 二、国赛论文标准章节结构

### 2.1 完整论文结构（按顺序）

```
1. 论文题目（不超过20字，简短精练、高度概括、准确得体）
2. 摘要（含关键词）
3. 问题重述
4. 问题分析
5. 符号说明
6. 模型假设
7. 模型建立
8. 模型求解
9. 模型结果分析
10. 模型优缺点评价
11. 模型改进方向
12. 参考文献
13. 附录
```

### 2.2 各章节写作要点

**① 问题重述**
- 用自己的语言重述赛题，清楚简明地阐述背景、条件和要求，展示对题意的理解。
- **不是对原题的完整拷贝**！信息量少时可适当扩充背景，信息量大时可精炼提炼核心问题。

**② 问题分析**
- 说明要解决的问题是什么、关键在哪里、思路和大致步骤。可归入模型建立部分，也可单独成节。
- 可对每一小问单独设置"问题X分析"。分析要中肯、确切、术语专业、简明扼要。
- **此处不写结论和具体求解结果**；建议在此做文献综述。

**③ 模型假设**
- 从题目所给条件/要求中作出假设；关键性假设不能缺，假设要切合题意，**不要罗列大量无用假设**。
- 数量控制在3-6个左右，**建议写出每个假设的理由**（假设内容+合理性依据+对模型的影响）。

**④ 符号说明**
- 论文中用到的每一个数学符号都必须说明其含义。
- 呈现形式：三线表格列出 **符号、含义、单位**；也可在使用时说明。
- 符号要符合阅读习惯，尽量用英文字母缩写（c表示cost，t表示time）。
- **所有符号在正文第一次使用时须说明**，即使已在符号说明表中列出。

**⑤ 模型建立**
- 每篇论文都必须有一个明确的数学模型（公式、算法、图表等数学结构），要求正确、完整、简洁。
- 模型要实用、有效、有特色，以解决问题有效为原则：**能用初等方法就不用高级方法，能用简单方法就不用复杂方法，能用多数人看懂的方法就不用少数人看懂的方法**。
- 对简单问题做出自己的特色：人无我有（别人想不到的敢于去想）；人有我新（别人容易想到的，你比他想得更全面更好）。
- 建立数学命题：叙述符合数学命题表述规范，尽可能论证严密，能用定理总结的尽量给出定理并证明。
- 简化模型：当基本模型过于复杂难于求解时，明确说明简化思想和依据，简化后的模型尽可能完整给出。
- 优化模型表述建议：建模前用表格列出所有已知条件；决策变量（数学语言+表格）；目标函数（数学表达式+通俗语言）；约束条件（逐个表示、逐个解释）；最后综合成完整表达式并给出模型属性。

**⑥ 模型求解**
- 说明计算方法/算法的原理、思想、依据和步骤。
- 若采用现有软件，说明采用理由和软件名称。
- 中间结果篇幅大可不列出，关键过程放附录。
- 数值求解：设法算出合理数值结果；不能求精确解时，给出不只一种解法，测试比较并做出评价。

**⑦ 模型结果分析**
- 最终数值结果的正确性和合理性是第一位的。
- 包含：结果表示、结果分析检验、模型检验及修正、**灵敏度分析和稳定性分析**。
- 题目要求回答的问题、数值结果、结论须一一列出；结果表示要集中、一目了然、直观、便于比较。
- 结果呈现：数值结果精心设计表格；能用图形图表更好；求解方案用图示更好；必要时作定性或规律性讨论。
- **灵敏度分析并非所有模型都必须做**，只有当结果对原始数据依赖性强且数据存在不确定性时才有必要。

**⑧ 模型优缺点评价**
- 基本原则：**优点要突出，缺点不回避**。优点来源：假设合理、建模方法创新、求解有特色。
- 优点简化后可在摘要中引用；**缺点只在正文此处说明，摘要中不提**。

**⑨ 模型改进方向**
- 由于时间限制未能实现的想法可在此提出；改变原题要求重新建模可在此做。
- 推广或改进时尽量使用已用过的术语，不玩弄新数学名词。

**⑩ 参考文献**
- 引用他人成果（包括网上资料）必须在正文引用处和参考文献中均明确列出。
- 正文引用处用方括号标示编号如[1][3]；引用书籍必须指出页码；参考文献按正文中引用次序列出。
- 文献类型标识：专著[M]，论文集[C]，报纸文章[N]，期刊[J]，学位论文[D]，报告[R]，标准[S]，专利[P]，网上电子公告[EB/OL]。
- 引用高水平期刊、近年新文献、适当引用英文文献。

**⑪ 附录**
- 包含：程序清单（至少主程序代码）、详细数值结果、详细公式推导和定理证明、更多图表。
- 结果和数据表格不要有错误，拿不准的宁可不列；主要结果正文已有，附录重复列出无妨。
- 如果确实没有源程序，明确说明"本论文没有源程序"——**无源程序或程序无法验证可能影响评奖**。

## 三、摘要写作（重中之重）

> 摘要是论文的第一道关口。评委用2-3分钟浏览摘要——写得好翻正文，写得差直接淘汰。**摘要占印象分50%+**。
> 全国评阅时首先根据摘要和论文整体结构进行初步筛选。

### 3.1 摘要评审三问

1. 这道题做完了吗？（所有小问都有方法和结果）
2. 用的方法合理吗？（模型选择有依据、数据处理有说明）
3. 结果是具体的吗？（每个问题后面有数字，而非模糊描述）

三个问题全答"是"才进入下一轮评审，任何一项"否"直接降档。

### 3.2 三段式（虎头-猪肚-豹尾）

| 段落 | 篇幅 | 内容 |
|------|------|------|
| **虎头**（总起段） | 3-5行 | 概括针对什么问题、建立了什么模型、用了什么方法、得到什么主要结果 |
| **猪肚**（逐问题段） | 每问180-250字 | 针对每个具体问题，说明用了什么方法、建了什么模型、用了什么算法、得到什么结论 |
| **豹尾**（总结段） | 2-3行 | 突出特色，交代灵敏度分析和误差分析结果，概括优缺点和推广方向 |

**五段式模板**（国赛标准，总起 + 三/四问 + 总结）：

```
第一段（总起，150-200字）：
本文针对[题目背景/具体问题]，结合[数据特征/问题特点]，综合运用[方法类别一]、[方法类别二]
与[方法类别三]，提出了系统的[解决方案名称]。

第二至四段（逐问题展开，每段180-250字），固定五步：
针对问题X：本问属于[问题类型判断]，需[题目具体要求]。
数据处理阶段：首先，对附件提供的[数据描述]进行[预处理操作一]与[预处理操作二]，剔除
[异常值类型/缺失值处理方式]，得到有效数据[N]条。接着，通过[特征工程/参数选择方法]确定
[关键特征/参数]。
模型建立阶段：然后，建立[模型全称]对该问题进行求解。模型的核心步骤为：(1)[步骤一描述]；
(2)[步骤二描述]；(3)[步骤三描述]，最终得到[模型输出形式]。
模型求解阶段：利用[求解工具/算法]对上述模型进行数值求解，得到[关键结果]，其中[具体数据一]
=[数值]，[具体数据二]=[数值]。
结果分析阶段：与[对比基准/原有方案]相比，本模型[效果描述]，[核心指标]提升/降低了
[百分比/绝对值]。结果表明该模型能够有效[解决什么问题]。

第五段（总结，150-200字）：
综上，本文通过[核心建模策略]，建立了涵盖[模型A]、[模型B]、[模型C]的系统解决方案。
在[关键指标]上取得了[具体效果，必须含数字]，各模型经[灵敏度分析/误差分析/交叉验证]检验，
结果稳健可靠。本文提出的方法框架为[应用领域]中的[问题类型]提供了一套[什么样的]解决方案。

关键词：5-6个，分号分隔；覆盖"模型类+方法类+领域类"三要素
```

### 3.3 摘要写作规范

- 人称：统一用"**本文**"，禁止"我们""笔者""本人"。
- 时态：用现在时/完成时（"建立了""得到了"），禁止将来时（"本文将..."）。
- 数据：必须给具体数值，禁止"大约""约"等模糊词；必须给有效数字（3.2%而非约3%）。
- 方法命名：首次全称，后续可用通用缩写（ARIMA、TOPSIS、SVM）。
- **禁止套话**："随着科技的发展""数学建模是一门重要的学科""本文具有重要的理论意义""得到了良好的效果"——一经发现直接扣分。
- 逻辑连接词：每个问题段落内部必须出现"**首先、接着、然后、最后**"四个连接词，分别对应数据处理、参数选择、模型建立、结果输出四个阶段。
- 篇幅：800-1200字（国赛），美赛英文300-500词；半页到2/3页之间，**不超过1页**。
- 摘要不要出现图片、表格和公式；尽量避免容易混淆的缩略语。
- 如果有多个问题，建议按问题分段处理。

### 3.4 关键词选择

- 3-5个（全流程课说3-8个），分号分隔，覆盖：模型类（1-2个）+方法类（1-2个）+领域类（1个）。
- 禁忌：不要用"数学建模""模型""分析""优化""问题""研究""方法"等泛化词汇。
- 示例：瞬态热传导；有限差分法；参数优化；二分搜索算法；蒙特卡洛模拟；热防护服装。

### 3.5 摘要扣分项与急救

| 扣分项 | 急救措施 |
|--------|----------|
| 无具体数字（"效果良好"） | 每个问题后强制写带数值结果，没算出来先留{}标记 |
| 字数不足<600字 | 每个问题至少180字，方法+过程+结果三段展开 |
| 套话充数 | 删除套话，替换为"做了什么+怎么做的+结果多少" |
| 方法遗漏（正文3模型摘要只提2个） | 正文和摘要方法列表一一对应核对 |
| 结构残缺（缺总起或总结段） | 五段式是国赛标配，缺一段扣分 |
| 摘要-正文不一致 | 摘要必须正文写完后写，写完再回正文验证每个数字 |
| 关键词太泛 | 必须写具体算法全称和数据领域 |

**提交前自检10条**：
1. 不看正文仅读摘要，能否完整说出"用了什么方法、怎么做的、结果是什么"？
2. 每个问题段落后是否有至少一个具体数值？
3. 是否出现"首先、接着、然后、最后"四个连接词？
4. 五段结构是否齐全？
5. 字数是否800-1200？
6. 是否出现"我们/笔者/可能/大概/随着科技发展"等禁忌词？
7. 正文每个模型名称，摘要是否都提及？
8. 摘要每个数字，正文中是否有出处且完全一致？
9. 关键词是否覆盖"模型+方法+领域"三要素？是否5-6个？
10. 是否包含灵敏度分析/误差分析结果？

## 四、Word排版要点

> 用Word写国赛论文核心只有三点：**样式统一、三线表、公式编辑器**。搞定这三样，Word排版不输LaTeX。

### 4.1 页面与样式（比赛开始前就设好）

- 页边距：上/下/左/右 2.5cm，A4纵向。
- 正文样式：宋体小四（12pt），1.5倍行距，首行缩进2字符，两端对齐，勾选"基于该模板的新文档"。
- 三级标题样式：

| 级别 | 字体 | 字号 | 对齐 | 额外 |
|------|------|------|------|------|
| 标题1（章） | 黑体 | 三号16pt | 居中 | 段前段后12pt，加粗 |
| 标题2（节） | 黑体 | 四号14pt | 左对齐 | 段前段后6pt，加粗，编号 |
| 标题3（小节） | 黑体 | 小四12pt | 左对齐 | 段前段后3pt，加粗，编号 |

- 用样式系统的好处：一键生成目录、全篇统一修改、导航窗格跳转。

### 4.2 三线表（国赛表格唯一规范）

**三线表 = 只有三条横线：顶线（粗）、栏目线（细）、底线（粗）。没有竖线，没有多余横线。**

制作步骤：
1. 插入表格 → 选中全表 → 表格工具-设计 → 边框 → 无边框；
2. 选中表头行 → 下框线 1pt（栏目线）；
3. 选中全表 → 上框线 1.5pt（顶线）；
4. 选中全表 → 下框线 1.5pt（底线）；
5. 表头文字加粗（Ctrl+B）。

**常见错误：三条线一样粗。必须是"粗-细-粗"**。

表格规范：
- 表格上方居中写：表1 供应商原始数据（黑体小五/五号）。
- 表格下方可写注释（宋体小五，如"数据来源：XX统计年鉴"）。
- 编号连续（表1、表2、表3...），不要跳号。
- 表格太宽：缩小字号为五号/小五，或改横向页面（单独一页）。

### 4.3 公式排版

- **不要用MathType**（不同电脑显示不一致、嵌入对象丢失），用Word内置公式编辑器：**Alt + =**。
- 公式居中 + 编号右对齐：用制表位（页面中央居中制表位 + 页面右端右对齐制表位），公式前Tab到中央，公式后Tab到右端写编号。
- 文中引用："如式(2-1)所示"，(2-1)用交叉引用自动生成。
- 多行公式：Shift+Enter换行，等号前右键"在此对齐"。
- **公式不能跨行**，如需断开在等号或加减号处断开。

### 4.4 图片

- 插入PNG（截图/位图）或矢量图（流程图导出EMF/WMF）；分辨率至少150dpi，不要直接屏幕截图。
- **图题在图片下方**："图1 SIR模型传播曲线"（宋体小五，居中，加粗"图1"）；图片上方不写标题。
- 图片位置：设为"嵌入文本行中"（不要用文字环绕），排版不会乱。
- 每张图都应有对应文字解释——只放图不解释会影响论文质量。
- 图应清晰标记横纵坐标表示的量及单位。

### 4.5 页码/页眉/目录/参考文献

- **封面不编页码，正文从第1页开始**：用"分节符-下一页"分隔封面和正文，页脚编辑时"取消链接到前一节"（关键），插入页码设置起始页码1。
- 目录：用样式系统后"引用→目录→自动目录"一键生成，内容变化后"更新域"。
- 参考文献：统一 GB/T 7714 格式（知网导出→选择GB/T 7714→复制）。期刊[M]、书籍[M]、网络[EB/OL]。

### 4.6 Word最易翻车的5个问题

1. **换电脑排版全乱**（字体缺失/样式不同）→ 比赛只用同一台电脑编译。
2. **图片位置乱跑** → 用"嵌入文本行中"不用"文字环绕"。
3. **页码调不对** → 没用分节符或忘了取消"链接到前一节"。
4. **公式和文字不对齐** → 行间公式独立段落居中，不要内嵌段落。
5. **最后页码变多/变少** → 另存PDF选"全部"，删除正文末尾多余空行。

### 4.7 最终格式检查清单

1. 页面A4，边距2.5cm
2. 正文宋体小四，标题黑体，公式Cambria Math
3. 行距1.5倍，表格内可1.0倍
4. 页码：封面无页码，正文从第1页，底部居中
5. 表格全部三线表（粗-细-粗），编号连续
6. 图片清晰≥150dpi，图题在下方，编号连续
7. 公式用编辑器（Alt+=），编号格式统一
8. 参考文献统一GB/T 7714，文中引用与列表一一对应
9. 确认要求.docx还是.pdf，两个都准备
10. 另存为PDF，打开确认显示正常

## 五、LaTeX排版要点（使用CUMCM模板）

> 核心就一句话：**你不需要"学"LaTeX，只需会改模板**。填标题、填摘要、填各小节内容、填参考文献。

### 5.1 为什么用LaTeX
- 公式排版无可挑剔；图表编号、参考文献自动管理；格式统一不会被人手误改。

### 5.2 5步上手
1. 复制模板文件夹，重命名为队伍编号/题目简称，不在原文件夹上改。
2. 改主文件 论文.tex 三处：\title、\begin{abstract}、\keywords。
3. 逐文件填充（\input引入各章节文件）。
4. 图片放 figures/，代码放 code/，用 \includegraphics 和 \lstinputlisting 引用。
5. 编译两次（生成目录和交叉引用）：`xelatex 论文.tex` 执行两遍。

### 5.3 模板文件结构与填写指南

```
制作模板-论文/
|-- 论文.tex        ← 主文件，编译入口
|-- cumcmthesis.cls ← 文档类（绝不修改）
|-- 1.引言.tex
|-- 2.总体分析.tex
|-- 3.模型假设.tex
|-- 4.符号说明.tex
|-- 5.模型的建立与求解.tex（主章节，引用子文件）
|-- 5.1.问题1的建立求解.tex
|-- 6.模型检验.tex
|-- 7.模型评价.tex
|-- 8.模型改进推广.tex
|-- ref.bib（BibTeX参考文献库）
|-- figures/  code/  fonts/
```

各章节要点：
- **引言**：问题背景（1-2页，可引文献）+ 问题重述（用自己的话概括每个小问）。
- **总体分析**：数据来源与特征 + 整体建模思路（画总体建模流程图）。
- **模型假设**：5-8条，每条编号并简要说明理由。
- **符号说明**：三线表列出符号、含义、单位。
- **模型建立与求解**（核心章节）：每个问题拆成独立子文件，按"具体分析→模型建立→模型求解"三子节。**关键原则：每个问题的求解部分必须包含四个要素——输入数据是什么→用了什么方法→输出了什么结果→结果说明什么。缺一即不完整。**
- **模型检验**（硬性要求）：灵敏度分析（参数±10%）、误差分析（MAPE/RMSE）、模型对比。
- **模型评价**：优点4-5条 + 缺点4-5条（写真实局限，不写"时间有限"）。
- **模型改进推广**：2-3条具体改进方向。

### 5.5 十大编译错误快速排错
1. Undefined control sequence → 命令拼错或缺宏包
2. Missing $ inserted → 文字中写了数学符号，放入数学模式$\alpha$
3. Extra } 或 Missing } → 花括号不匹配
4. File not found → \input路径/文件名错误
5. xxx.png not found → 图片不在figures/或扩展名不对
6. Double subscript → $x_i_j$改为$x_{ij}$
7. tabular中&数量不对 → N列每行应有N-1个&
8. 中文引号乱码 → 用``...''或中文引号
9. 编译卡死 → 删.aux/.toc/.out重编译
10. 表格太宽 → 调列宽或longtable小字号

## 六、灵敏度分析章节写作

**国赛硬性要求，缺了直接降档。**

写作模板：
```
\section{模型检验}
\subsection{灵敏度分析}
改变XXX参数±10%，结果变化如表X所示，排名保持稳定，说明模型具有良好鲁棒性。
\subsection{误差分析}
预测值与实测值比较，MAPE=3.2%，说明模型精度满足要求。
```

三种典型写法：
1. **评价/排序类**：权重±10%扰动，前两名排名不变 → 结果稳健。
2. **优化类**：约束右端±20%，看最优值变化；算影子价格（资源约束每增1单位的利润增量），判断瓶颈。
3. **机理/预测类**：关键参数（传染率β、冷却系数等）取不同值，对比峰值/拐点/误差变化；或蒙特卡洛1000次传播不确定性，给出结果波动范围与安全裕度。

## 八、获奖论文的流程框架模式（高分模型组合）

> 国赛获奖论文几乎都是"多模型组合"打法：一个评价/预测/优化主模型 + 若干辅助模型 + 完整的检验链条。以下是高分区论文的通用流程框架模式。

### 8.1 评价类获奖框架：AHP-EWM-TOPSIS 组合

```
问题（多个方案/对象排序）
  ↓ 第1步：建立指标体系（查文献定维度，一级→二级，画层次图）
  ↓ 第2步：数据预处理（正向化：成本型取倒数；标准化：min-max/z-score）
  ↓ 第3步：组合赋权
  │   AHP主观权重（专家两两比较+一致性检验CR<0.1）
  │   + 熵权法客观权重（信息熵→差异系数→权重）
  │   → 组合权重 w = α·w_ahp + (1-α)·w_ewm
  ↓ 第4步：TOPSIS排序（加权标准化→正负理想解→欧氏距离→贴近度Ci）
  ↓ 第5步：灵敏度分析（权重±10%，排名是否稳定）
  ↓ 第6步：结果解读 + 差异化建议
```

**完整代码链**：`entropy_topsis(data, benefit_cols)` —— 正向化→min-max标准化→信息熵→权重→加权矩阵→最优/最劣距离→贴近度。

### 8.2 聚类+预测获奖框架：K-means → 随机森林/LSTM

```
问题（C题数据类，如客户分群/销量预测）
  ↓ 第1步：数据清洗（缺失值、异常值3σ/IQR、标准化）
  ↓ 第2步：K-means聚类（肘部法则+轮廓系数定K → 分群 → 每簇画像雷达图）
  ↓ 第3步：分类/预测建模
  │   分类：逻辑回归基线 → 随机森林/SVM/XGBoost对比（AUC/ROC/混淆矩阵）
  │   预测：ARIMA/GM(1,1)基线 → LSTM/Prophet对比（MAPE/RMSE）
  ↓ 第4步：特征重要性（随机森林feature_importances_，Top3可视化）
  ↓ 第5步：模型检验（交叉验证、误差分析、灵敏度）
```

### 8.3 优化类获奖框架：机理+NSGA-II 多目标优化

```
问题（A/B题，多目标冲突，如成本最小+效率最高）
  ↓ 第1步：机理/逻辑建模（微分方程 或 决策变量-目标-约束三件套）
  ↓ 第2步：判断类型（线性→LP精确解；整数/0-1→MIP；非线性/多目标→智能算法）
  ↓ 第3步：多目标优化 NSGA-II（非支配排序→Pareto最优解集）
  ↓ 第4步：从Pareto前沿选折中方案（加权打分/TOPSIS辅助决策）
  ↓ 第5步：灵敏度（约束右端±20%、影子价格） + 蒙特卡洛鲁棒性验证
```

### 8.4 创新型算法组合库（2025国赛创新型算法汇总）

**优化类**（典型组合）：GA+SA、PSO+TS、ACO+Greedy、SVM+GA、FNN+PSO、MOPSO+EWM、GA+约束规划、SA+LP、贝叶斯优化+RF、禁忌搜索+0-1整数规划。

**评价类**（典型组合）：AHP+熵权法、TOPSIS+灰色关联、模糊综合评价+BP神经网络、PCA+SVM、DEA+TOPSIS、灰色预测+马尔可夫链、随机森林+AHP、聚类+因子分析。

**预测类**（典型组合）：ARIMA-LSTM、RF-GA、CNN-LSTM、SVM-PSO、GM(1,1)-BP、GRU-Attention、XGBoost-贝叶斯优化、马尔可夫链-ETS、小波分析-LSTM、LSTM-SVR、LightGBM-Stacking。

> **组合原则**：三类创新方向任选其一——①算法改进创新（改经典算法适配赛题）②跨领域模型迁移（如用SIR模型模拟舆论传播）③多模型融合组合（如灰色-BP神经网络）。禁止无意义套模型。

### 8.5 优秀论文五大看点（评委视角）

1. 问题理解 2. 模型合理 3. 数据可靠 4. 结果有效 5. 表达清晰。

**学生比赛常见错误**：
- 错误1：看到关键词直接套模型（不分析问题本质）。
- 错误2：模型堆砌（一堆模型没有内在逻辑关系）。
- 错误3：只计算，不解释（结果没有业务/物理意义解读）。

## 九、国赛格式与违规红线

| 违规项 | 正确做法 | 后果 |
|--------|----------|------|
| 论文正文查重 | 全文重复率≤25% | 超了取消评奖资格 |
| 代码查重 | 相似度≤50%（MOSS检测） | 超了取消评奖资格 |
| 论文出现学校/队员名 | 绝对不能出现 | 取消评奖资格（部分省份） |
| 未按时提交 | 提前1小时提交 | 0分 |
| 提交格式错误 | PDF（非Word/图片/压缩包） | 0分 |
| 抄袭他人论文 | 引用必须标注 | 取消资格+通报学校 |

**查重安全做法**：
- 公式推导部分最容易重复（大家都抄同一本教材）——用自己的话改写。
- 引言/背景最容易不小心抄——必须自己写。
- 代码：自己写/自己改，变量名用自己命名习惯，代码结构有自己的逻辑，不直接复制GitHub完整项目，AI生成代码要改。

**提交环节**：
- 提前1小时提交（最后半小时系统必崩）。
- 确认文件格式PDF、文件大小不超标；下载自己提交的文件确认完整。
- MD5校验：提交前记录MD5，提交后核对。
- 提交失败立刻截图+联系组委会应急通道。
