## 一、[Mad25] 锂电池老化动力学综述（J.Phys.Conf.Ser. 2025）

> **位置**：Undermind `/A题论文/问题1_退化特征与影响因子/1_退化机理综述/`

### 1. 内部老化机理全景
| 机理 | 触发条件 | 影响 |
|------|---------|------|
| **SEI膜生长增厚** | 高温存储/循环（55-60°C）、高SOC | 消耗活性锂（LLI）、增加DC电阻与交流阻抗、降功率与寿命 |
| **析锂（Lithium Plating）** | 低温充电、高倍率充电、过充、高SOC | 不可逆容量损失、内阻增加、锂枝晶穿透隔膜→短路→热失控 |
| **正极退化/活性物质损失LAM** | 机械应力（体积变化）、高温、深度放电 | NCA电池H2-H3相变→微裂纹→岩盐相，容量功率双降 |
| **电解液分解** | 过充电、极高温度（>80°C） | 产气→电池膨胀失效 |

### 2. 温度影响的量化规律（问题1核心）
- **高温**：>25°C（尤其60-80°C）显著加速SEI生长与电解液氧化；80°C时SEI分解转松散颗粒。
- **低温**：锂离子迁移变慢→析锂→功率效率下降。
- **定量规律**：
  - 温度依赖用 **Arrhenius定律** 参数化建模（LAM、LLI）；
  - 时间依赖遵循 **t^0.5（平方根）规律** —— 老化随时间推移速率放缓（扩散控制SEI生长）；
  - **两阶段老化**：低温循环后高温暴露 → "死锂"初始损失 → 析锂引发加速老化。

### 3. 过充过放与库伦效率
- 过充：析锂 + 电解液分解 + 产气；过放：电极退化。
- **库伦效率（CE）下降 ↔ 活性锂损失LLI + 活性物质损失LAM** —— CE是健康状态在线评估的半经验指标。

### 4. 关键定量数据（可写进论文）
- 日产聆风电池模块老化拐点前 ≥ **2033次等效全循环**；
- 富镍/SiC电池70%SOC、25°C存储10个月：**容量偏差翻倍**，阻抗稳定；
- **55°C存储210天，容量损失与SOC直接相关**；
- ANN-SOH估算模型可达 **RMSE 1.67%**。

### 5. 特征提取方法
- **ICA（增量容量分析）+ DVA（差分电压分析）**：量化LAM/LLI/电导率损失；
- **EIS（电化学阻抗谱）**：分析内阻增加与动力学特性；
- 模型：P2D电化学模型、分数阶模型FOM、GPR/ANN/LSTM数据驱动。

## 二、[Ver22] 锂电池老化特性与建模综述（IEEE TTE 2022）★核心

> **位置**：Undermind `/A题论文/问题1_退化特征与影响因子/1_退化机理综述/`

### 1. 三大老化模式（问题1机理论述的框架）
| 模式 | 定义 | 后果 |
|------|------|------|
| **LLI 锂库存损失** | SEI形成、分解反应、析锂消耗活性锂 | 容量衰减 |
| **LAM 活性物质损失** | 电极表面层生长、循环裂纹剥落、结构退化 | 容量衰减 + 功率下降 |
| **CL 电导率损失** | 集流体腐蚀、粘结剂分解 | 内阻上升 |

### 2. 关键机理细节
- **SEI膜（阳极）**：初期生长快，后期按 **t^0.5（√t）规律**增长（扩散控制）；
- **析锂**：低温（<20°C）、高倍率充电、低SoC → 锂金属沉积，严重LLI，可能枝晶短路；**通常在老化曲线产生"拐点"（knee point）**；
- **过渡金属溶解（阴极）**：高电压高温下HF腐蚀阴极，锰溶解迁移至阳极加速SEI生长。

### 3. 老化应力因子影响趋势（因子量化依据）
| 因子 | 影响规律 |
|------|---------|
| **温度** | 日历老化：**温度每升高10°C老化速率翻倍**（经验法则）；循环老化：高温加速副反应、低温触发析锂 |
| **SoC** | 日历老化：高SoC加速SEI生长；循环老化：**50%平均SoC附近老化最轻** |
| **放电深度DoD** | 符合 **Wöhler曲线**：DoD越大可循环次数越少；但按Ah吞吐量计，大DoD不一定更差 |
| **电流倍率C-rate** | >2C显著增加机械应力和析锂风险；**老化速率随倍率指数增长** |

### 4. 经验/半经验老化模型公式库（可直接用）
| 模型 | 公式 | 参数说明 |
|------|------|---------|
| 幂律/吞吐量模型 | $Q_{loss} = f(SoC,T)\, t^{z}$ 或 $Q_{cycl} = f(SoC,T,DoD,I)\, Ah^{z}$ | z ∈ 0.5~0.8，z=0.5代表扩散限制SEI生长 |
| **Arrhenius温度模型** | $k = A\, e^{-E_a/(RT)}$ | $E_a$激活能、R气体常数、T绝对温度 |
| **倍率耦合Arrhenius** | $Q_{loss} = B(I)\, e^{(-E_a+\alpha|I|)/(RT)}\, Ah^{z}$ | 电流修正激活能 |
| DoD指数模型 | $CL(DoD) = a e^{b\,DoD} + c e^{d\,DoD}$ | 双指数 |

### 5. 应力因子相关性（问题1"因子耦合"论述）
- **温度×倍率**：低温下中等倍率也可能因阳极极化析锂；高温下倍率影响因离子扩散增强而显得较小；
- **SoC×温度**：高SoC下温度加速作用更显著；
- 多数经验模型未考虑交叉耦合 → 范围外使用误差巨大。

### 6. 退化曲线形态
- 日历老化初期 **√t形态**（SEI扩散控制）；
- 可能**容量初期微弱回升**（低SoC存储，阳极活性锂重新分布）；
- **拐点**：析锂主导时从线性/对数转为加速衰减；
- **多阶段线性化**：可把寿命分为四个线性阶段简化建模。

## 三、[Xu21] 放电温升对退化影响实验（IOP EES 2021）★因子解耦

> **位置**：Undermind `/A题论文/问题1_退化特征与影响因子/2_影响因子实验/`

### 1. 实验设计（精巧：解耦倍率与温升）
- **两个倍率**：C/2（0.5C）vs 3C；
- **基准温度**：45°C（厂商允许最高运行温度）；
- **两种温控**：
  - **环境温控**（Test#1/#3）：电池置于45°C恒温箱，放电时表面温度随倍率上升（常规场景，倍率效应+温升耦合）；
  - **表面温控**（Test#2/#4）：PID加热系统+铝板把表面温度恒定在 **45±1°C**，消除放电温升，**单独提取"倍率非热效应"**。

### 2. 关键数据（问题1因子量化直接可用）
| 指标 | C/2 | 3C |
|------|-----|-----|
| 表面最高温升（45°C环境） | **5.2°C** | **20.6°C**（平均11.9°C） |
| 到EOL(80%)循环数（环境温控） | >1100 | **约750-800** |
| 到EOL(80%)循环数（表面温控） | >1100 | 约900-950 |
| 1100循环后剩余容量（环境温控） | ~81-82% | **~72%** |
| 1100循环后剩余容量（表面温控） | ~81-82% | ~77.5%（比环境温控高5.53%） |

### 3. 核心结论：谁占主导？
- **放电倍率的非热效应占主导**（容量损失主因）；
- **温升效应**：3C放电温升11.9°C在1100循环后贡献 **5.53%** 额外容量损失；
- 解耦温升后3C仍显著快于C/2（差4-5%）—— 高倍率电流本身的物理/化学损伤是寿命缩短核心。

### 4. 内阻
- 本文未给内阻/EIS数据（只测放电容量）；可参考其他文献补内阻。

### 5. 对问题1的启示
- **倍率与温度可以实验解耦** → 仿真数据构建时分别建模"温度效应"（Arrhenius）与"倍率非热效应"（乘数因子），再叠加；
- 量化贡献时可仿此给"各因子单独贡献率"。

## 四、[Wil20] SOH判断特征比较分析（IJPHM 2020）

> **位置**：Undermind `/A题论文/问题1_退化特征与影响因子/4_健康特征提取/`

### 1. 四大SOH特征（退化特征库）
| 特征 | 物理含义 | 测量方法 | 随老化趋势 |
|------|---------|---------|-----------|
| **放电容量 Q** | 存储电荷能力 | 放电电流对时间积分 | 指数衰减 |
| **内阻 R** | 阻碍电流程度 | 充电末微小电流脉冲测dV/I | 上升 |
| **恒流充电时长 CCCT** | CC阶段持续时间 | 测CC阶段时长 | **缩短**（锂嵌入位点减少） |
| **恒压充电时长 CVCT** | CV阶段持续时间 | 测CV阶段时长 | **增加**（内阻+扩散率下降） |

### 2. 特征灵敏度随工况变化（重要：无单一最优特征）
| 工况 | 最优特征 |
|------|---------|
| 简单恒流放电 | 容量 + CCCT（趋势一致、噪声小） |
| 变倍率工况 | CVCT + 内阻（对倍率依赖小） |
| 变放电深度工况 | **内阻最优**（准线性增长、噪声极低） |

### 3. 定量数据
- Battery A：容量 1.1Ah → 800循环后 <0.4Ah；内阻 0.15Ω→0.19Ω；
- CCCT：110分钟→20分钟（800循环）；CVCT：40分钟→波动至70分钟→700循环骤降；
- Battery C（变DoD）：内阻 0.15Ω→**0.35Ω准线性**。

### 4. 特征融合方法（可借鉴）
- Beta分布表征特征分布（与SOH同取[0,1]）；
- 加权平均 + 最大似然估计每循环SOH点值；
- 按预测误差迭代更新权重 + 10循环滑动平均；
- **融合后SOH曲线更线性、噪声更小**（问题1"多特征综合评估"加分点）。

## 五、[Sto19] 高温汽车工况容量衰减DOE分析（IEEE EV 2019）★因子量化

> **位置**：Undermind `/A题论文/问题1_退化特征与影响因子/3_因子量化与灵敏度/`

### 1. 试验设计（全因子）
- **充电倍率**：0.5C / 1C / 2C（3水平）；
- **DoD（SoC窗口）**：15-85%（70%DoD）/ 10-90%（80%DoD）/ 5-95%（90%DoD）（3水平）；
- **常量**：45°C恒温、平均SoC=50%、FUDS联邦城市驾驶工况；
- 共 **9个测试用例**（3×3全因子）。

### 2. 主效应量化结果
- 最差/最佳工况衰减速率比 ≈ **1.6倍**；
- **DoD**：增大DoD加速老化；**80-90%DoD区间老化加速显著高于70-80%**（非线性）；
- **充电倍率**：
  - 按时间计：高倍率近似线性增加老化；
  - 按Ah吞吐量计：低倍率反而衰减率更高（低电流暴露时间更长）。

### 3. 三阶段衰减（问题1"正常运行→劣化→失效"直接依据）
| 阶段 | 时间 | 特征 |
|------|------|------|
| Phase 1 | 第一个月内 | **极高的初始容量衰减率** |
| Phase 2 | 第1-6个月 | **近似线性**，相对容量估计误差<0.5% |
| Phase 3 | 最后1-2个月 | **老化加速** |
- **关键阈值：大多数电池在 SOH 82-85% 开始老化加速**（失效临界的前兆）。

### 4. 响应面模型（因子交互量化）
$$Y = \theta_1 + \theta_2 A + \theta_3 B + \theta_4 AB + \theta_5 A^2 + \theta_6 B^2 + \theta_7 A^2B + \theta_8 AB^2 + \theta_9 A^2B^2$$
- A=充电电流（编码-1,0,1），B=DoD（编码-1,0,1）；
- Ah吞吐量模型：C-rate为负影响（~-1.8e-5），DoD为正影响（~1.8e-5），B²显著；
- 时间模型：A、B均正影响，DoD影响略大。

### 5. 结论（因子排序）
- **早期（Phase1）：充电倍率影响最显著，DoD相对不重要**；
- **中后期（Phase2&3）：DoD变得更显著，且加速衰减**；
- **综合：随老化推进，DoD影响力上升，充电倍率相对下降**；
- 高温下 **循环时间比Ah吞吐量更能反映老化状态**。

## 六、[Str24] 多阶段老化数据集（Scientific Data 2024）

> **位置**：Undermind `/A题论文/问题1_退化特征与影响因子/3_因子量化与灵敏度/`

### 1. 数据集规模（仿真数据参考库）
- 三星 **INR21700-50E，标称容量4.9Ah**；
- **279颗独立电池、71种老化条件（93个测试点）**、累计老化近250年；
- 部分长寿命电池等效全循环 **~4000次**。

### 2. 实验设计（两阶段）
- **Stage 1（非模型驱动DoE）**：日历老化用**全因子**，循环老化用**条件拉丁超立方（cLH）**；
- **Stage 2**：**参数个体最优实验设计（pi-OED）** 精细化参数估计 + cLH基准对比。

### 3. 因素与水平（A题仿真数据参数范围来源）
- **环境温度**：10 / 23 / 35 / 45 °C；
- **SoC**：日历老化5-100%；循环老化限制在 **20-80%**（避免CV阶段）；
- **倍率**：充电 [0.05-1]C，放电 [0.05-2]C；
- 制造商限值：最大充电4.9A(1C)、放电9.8A(2C)。

### 4. 容量衰减规律
- 观测到**亚线性、超线性、拐点形（knee-shaped）**退化趋势；
- 高温（45°C）显著加速日历/循环老化；
- **SoC>80%日历老化呈非单调行为** → 后续设计限制SoC<80%；
- 低温（10°C）与高温（45°C）的RPT给电池额外循环压力。

### 5. 对A题的启示
- 提供**多因素矩阵实验设计**的完整模板（温度×SoC×倍率）；
- RPT对照组设计可**量化测试本身对老化的贡献**（类似Xu21的对照组思路）。

## 七、[For12] 电池退化建模的最优实验设计（ASME DSCC 2012）

> **位置**：Undermind `/A题论文/问题1_退化特征与影响因子/3_因子量化与灵敏度/`

### 1. OED原理（方法论）
- 核心：在资源约束下**最大化试验信息量** → 最小化参数估计协方差；
- 数学基础：**Fisher信息矩阵** $F = \frac{U^TU}{\sigma^2}$ + Cramér-Rao下界；
- 目标：**D-优化（最大化det F）** → 最小化参数估计误差超椭球体积。

### 2. 选点方法（DETMAX）
- 候选空间：CCCV循环参数化（V_min∈{2.0-3.5V}、V_max∈{2.1-3.6V}、I_max∈{0.5-2.5C}）= **680个候选循环**；
- DETMAX算法通过"交换"试验点最大化 det(U^TU) → **选定14个试验点（10拟合+4验证）**。

### 3. 黑盒退化模型（参数可作仿真参考）
$$\dot{h}(I,V) = \beta_1 + \beta_2|I| + \beta_3 V + \beta_4|I|^2 + \beta_5 V^2 + \beta_6|I|V + \beta_7 V^3$$
- 参数（Table 2）：β₁=1.2126e-7, β₂=-3.143e-8, β₃=-1.3861e-7, β₄=2.5287e-10, β₅=5.2377e-8, β₆=8.2662e-9, β₇=-6.5166e-9。

### 4. 对比优势（论文"方法创新"加分点）
- 仅14个电池即可准确识别7-10个模型参数；
- 实验持续429天仍高效；
- **揭示"容量衰减对电压的依赖"：高电压(≥3.4V)老化显著快于低电压(≤3.1V)** —— 传统模型常忽略。

### 5. 对A题借鉴
- **因子空间定义 + 仿真预生成候选工况 → DETMAX/D优化选点**（安排多因素退化试验的严谨方法）；
- **回归向量转化法**：把时变电压/电流轨迹积分转化为静态回归向量 u_j，再分析敏感性。
