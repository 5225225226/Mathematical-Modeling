## 五、仿真数据构建映射表（数据→来源）

> 问题1建模时，每个仿真数据生成项都应标注其来源依据（竞赛评分点"数据取值依据"）。

| 仿真数据项 | 生成方式 | 来源依据 |
|-----------|---------|---------|
| 容量随循环衰减曲线 | 幂律/双指数 + 三阶段 + 拐点 + 容量再生 | U2公式 + U5三阶段 + L1容量再生 |
| 温度加速 | Arrhenius k=A·e^(-Ea/RT)，10°C翻倍 | U2 + U1 |
| 倍率影响 | 倍率指数增长 + 非热效应主导 | U2 + U3 |
| 内阻增长 | 随老化上升（变DoD下准线性） | U4 |
| 环境温度范围 | 10/23/35/45°C | U6 |
| 批次电池差异 | 正态分布初始容量/内阻 + 异常电池 | L2 |
| 健康特征 | 容量/内阻/CCCT/CVCT四维 | U4 |
| 试验设计矩阵 | 全因子：倍率×DoD | U5 + U7(OED) |
