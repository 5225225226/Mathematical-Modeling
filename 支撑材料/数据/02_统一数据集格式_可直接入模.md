# 统一数据集格式说明（可直接入模）

> **用途**：把问题1（退化特征 + 影响因子）与问题2（SOH评估 + RUL预测）所需的全部数据，统一成一套**标准 CSV Schema**，字段命名、单位、类型一致，代码可直接 `pandas.read_csv` 读取训练，无需再人工清洗。
>
> **承接关系**：本格式统一自 `00_数据汇总说明.md`（数据来源总览）与 `01_数据来源清单.md`（逐条来源）；数据源含真实公开数据集 + 仿真构建。
>
> **整理时间**：2026年8月

---

## 一、设计目标与使用流程

### 1.1 设计目标
1. **一个问题一套表**：问题1（退化特征/因子量化）用 `battery_meta + cycle_features`；问题2（SOH/RUL）在同一套表上直接消费；
2. **每个字段可溯源**：每个字段标注数据来源（真实数据集文件名 / 仿真构建 / 计算派生）；
3. **入模零转换**：字段名即特征名，单位统一，类型明确，附 pandas 读入示例；
4. **跨数据源可合并**：NASA / CALCE / MIT快充 / 仿真数据统一字段后可直接纵向拼接。

### 1.2 使用流程（三张表）
```
原始数据源（NASA / CALCE / MIT快充 / 仿真生成器）
        │  按 §四 映射规则字段标准化
        ▼
统一CSV：battery_meta.csv（每电池1行，静态工况）
        + cycle_features.csv（每电池每循环1行，健康特征+标签）
        + (可选) eis_spectrum.csv（EIS谱，Zhang2020类数据）
        │
        ▼
问题1：阶段划分、特征体系、因子量化（RF/灰色关联/熵权）
问题2：SOH多特征融合回归、EEMD-GRU RUL预测、工况扰动
```

## 三、Schema 定义（字段字典，含来源）

### 3.1 `battery_meta.csv` — 电池静态档案（每电池一行）

| 字段 | 类型 | 单位 | 说明 | 问题1用途 | 问题2用途 | 数据来源 |
|------|------|------|------|----------|----------|---------|
| `battery_id` | str | — | 电池唯一ID（主键，外键关联 cycle_features） | 分组 | 分组/迁移 | 数据源文件名或 `SIM_i` |
| `chemistry` | str | — | 化学体系：`LFP` / `NCM` / `NCA` / `LCO` | 分组、机理差异 | 模型泛化约束 | 数据源标注 |
| `cell_format` | str | — | 电池规格：`18650` / `21700` / 软包 | 分组 | 分组 | 数据源标注 |
| `rated_capacity_Ah` | float | Ah | 额定容量（SOH 分母） | SOH基准 | SOH 计算 | 数据源规格（NASA 2Ah [L1]；MIT 1.1Ah [Sev19]） |
| `nominal_voltage_V` | float | V | 额定电压 | — | — | 数据源规格 |
| `temperature_C` | float | °C | 环境温度 | **温度因子**（Arrhenius 输入） | 工况特征/扰动设置 | NASA 约24~43°C；MIT快充固定30°C；仿真按映射表 [U6 Str24] |
| `charge_rate_C` | float | C | 充电倍率（快充段） | **倍率因子**（指数增长+非热效应 [Ver22][Xu21]） | 工况特征 | MIT快充 72策略1~6C；仿真按 [U5 Sto19] |
| `discharge_rate_C` | float | C | 放电倍率 | 倍率因子 | 工况特征 | MIT固定4C；NASA ≤2A；仿真按 [Str24] |
| `dod_pct` | float | % | 放电深度 | **DoD因子**（Wöhler [Sto19]） | 工况特征 | MIT约80%；仿真按 [U5] 70/80/90% |
| `soc_window` | str | % | 循环 SoC 窗口，如 `"0-100"` / `"20-80"` | **SoC窗口因子** | 工况特征 | 仿真按 [Ver22][Str24] |
| `charging_strategy` | str | — | 充电方式编码：`CC`/`CV`/`CC-CV`/`Fast_6C-4C` 等 | **充电方式因子** | 工况特征 | 数据源协议文件 |
| `v_upper_V` | float | V | 充电截止电压 | 过充边界 | 过充扰动 | 数据源（MIT 3.6V [Sev19]） |
| `v_lower_V` | float | V | 放电截止电压 | 过放边界 | 过放扰动 | 数据源（MIT 2.0V [Sev19]） |
| `eol_threshold_pct` | float | % | EOL判据（容量保持率）：NASA 70，MIT 80 | 失效阈值 | RUL 标签分母 | [L1]（70%）与 [Sev19]（80%）**注意不一致** |
| `batch_id` | int | — | 试验批次（批次差异） | 批次效应 [L2] | 跨批次迁移 | 数据源批次（MIT分3批） |
| `source_id` | str | — | 数据源标识：`NASA_B5` / `MIT_Sev19` / `SIM` | 溯源 | 溯源 | 本表约定 |
| `source_ref` | str | — | DOI / 链接 | 溯源 | 溯源 | 见 §五 来源表 |

### 3.2 `cycle_features.csv` — 循环级健康特征 + 标签（每电池每循环一行）

| 字段 | 类型 | 单位 | 说明 | 问题1用途 | 问题2用途 | 数据来源 |
|------|------|------|------|----------|----------|---------|
| `battery_id` | str | — | 外键（关联 battery_meta） | 分组 | 分组 | 同上 |
| `cycle` | int | 循环 | 循环序号（1-based） | **主时间轴** | 序列时间步 | 各数据源循环计数 |
| `capacity_Ah` | float | Ah | 该循环参考放电容量（RPT 或当次放电） | **容量衰减曲线** | SOH 序列 / RUL 预测目标 | NASA 放电数据；MIT 每循环容量 [Sev19]；仿真 [U2+U5+L1] |
| `soh` | float | — | `capacity_Ah / rated_capacity_Ah` | 阶段划分输入 | **SOH 目标** | 计算派生 |
| `internal_resistance_ohm` | float | Ω | 内阻（80%SOC 脉冲 或 RPT 内阻） | **内阻增长特征** [Wil20] | SOH 输入特征 | MIT 脉冲内阻 [Sev19]；NASA 阻抗；仿真 [U4] |
| `ccct_min` | float | min | 恒流充电时长 | **CCCT 特征**（老化缩短 [Wil20]） | SOH 输入特征 | 原始充放电曲线反推；仿真 [U4] |
| `cvct_min` | float | min | 恒压充电时长 | **CVCT 特征**（老化增加 [Wil20]） | SOH 输入特征 | 同左 |
| `ce` | float | — | 库伦效率（放电容量/充电容量） | 可在线健康特征 [Mad25] | SOH 输入特征 | 计算派生（LFP 接近1需注意） |
| `q_ref_Ah` | float | Ah | RPT 参考容量（与 capacity_Ah 分离，作退化真值） | 退化真实标签 | RUL 训练真值 | RPT 规程 |
| `phase_label` | int | — | 阶段标签：`1`正常 / `2`劣化 / `3`失效 | **三阶段划分输出** | 阶段感知预测 | 计算派生（分段线性+拐点检测 [Sto19]） |
| `knee_cycle` | int | — | 加速拐点循环号（SOH 82~85% [Sto19]） | 拐点标记 | 预警节点 | 计算派生 |
| `rul_cycles` | float | 循环 | 剩余寿命标签 `= t_EOL - cycle`（EOL 按 `eol_threshold_pct`） | — | **RUL 回归目标** | 计算派生 |
| `is_eol` | bool | — | 是否已达 EOL 阈值 | 失效判据 | 区间估计 | 计算派生 |
| `source_id` | str | — | 数据源标识 | 溯源 | 溯源 | 同上 |

### 3.3 `eis_spectrum.csv` — EIS 谱（可选）

| 字段 | 类型 | 说明 | 用途 | 数据来源 |
|------|------|------|------|---------|
| `battery_id` | str | 外键 | 退化模式辨识 | Zhang2020 [Zha20] |
| `cycle` / `soh` | int/float | 测量点 | LLI/LAM 识别 | [Zha20] |
| `freq_Hz` | float | 激励频率 | EIS 谱线 | [Zha20] |
| `z_real_ohm` / `z_imag_ohm` | float | 阻抗实部/虚部 | EIS 谱线 | [Zha20] |

## 六、入模示例（pandas 直接读取）

```python
import pandas as pd, numpy as np

meta = pd.read_csv("dataset/battery_meta.csv")
feat = pd.read_csv("dataset/cycle_features.csv")

# 关联两张表（宽表，每行 = 电池×循环 + 静态工况）
df = feat.merge(meta, on="battery_id", how="left")
df = df.sort_values(["battery_id", "cycle"]).reset_index(drop=True)

# ---- 问题1：因子量化（随机森林重要性）----
# X = 工况因子（已数值化），y = 容量衰减率（对数差分）
factor_cols = ["temperature_C", "charge_rate_C", "discharge_rate_C",
               "dod_pct", "cycle"]
df["decay_rate"] = -np.log(df["capacity_Ah"] / df.groupby("battery_id")["capacity_Ah"].shift(1))

# ---- 问题2a：SOH 多特征融合回归 ----
soh_features = ["internal_resistance_ohm", "ccct_min", "cvct_min", "ce"]
X_soh = df[soh_features];  y_soh = df["soh"]

# ---- 问题2b：RUL 序列预测（EEMD-GRU）----
# 每电池取滑动窗口 [t-L+1 .. t] 的 soh 序列 → 预测 rul_cycles
L = 30
def make_seq(df_b, L):
    s = df_b["soh"].values; r = df_b["rul_cycles"].values
    X, y = [], []
    for t in range(L, len(s)):
        X.append(s[t-L:t]); y.append(r[t])
    return np.array(X), np.array(y)
```

## 八、数据质量与注意点（关键约束）

1. **EOL 阈值不一致（最重要）**：NASA/题设 = **70%**，MIT快充（Sev19/Zha20）停在 **80%**。
   - RUL 训练若用 MIT 数据：只能支持 `eol_threshold_pct=80` 的标签；要 70% 阈值需 **NASA/CALCE** 数据或模型外推（外推需注明误差风险）。
   - 推荐：**70% RUL 用 NASA/CALCE；MIT 快充用于快充策略量化 + EIS 退化模式 + SOH 特征融合**。
2. **温度因子**：MIT 数据恒温 30°C，**不能**从该数据量化温度权重；温度因子需仿真注入（Arrhenius，来源 [U2][U1]）或 Str24 数据。
3. **化学体系差异**：MIT 为 LFP（主导机理 SEI+析锂），NASA 为 LCO，机理表述需与 `chemistry` 对应。
4. **缺失值策略**：`internal_resistance_ohm`/`ccct_min`/`cvct_min`/`ce` 缺失时，用同一电池前向填充；仍缺则该特征置 NaN 并在对应模型剔除。
5. **LFP 库伦效率**接近 1、噪声大，作 `ce` 特征价值有限，可选剔除。
6. **容量再生尖刺**保留在 `capacity_Ah` 中（问题2 EEMD 需用它），不要在数据层平滑删除；如需平滑，另存 `capacity_Ah_smooth` 列。
7. **单位强制**：温度统一 °C，倍率统一 C，内阻统一 Ω，时长统一 min，容量统一 Ah——入模前用 assert 校验。
